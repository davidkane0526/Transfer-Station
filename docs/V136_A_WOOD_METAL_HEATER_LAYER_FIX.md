# V136 · 平台 A 木质隔热、加热片与银色吸附块的层级纠正

2026-11-11 用户通过爆炸图明确指出：
- 黄色的中间层是**木质隔热板**，不是铜层或上方金属块的一部分。
- **加热片和温度传感器必须处于木层与上方金属块之间**，装配逻辑不能将木层和金属层融合成一个部件。
- 真空吸气通道应埋在银色金属块内部，**不能在金属块中单独运动**。

## V136 改动

| 装配顺序 | ID | 工程模型 |
|---|---|---|
| 1 | A32 | 下部黑色底座，9mm；原正面调节板与下部支承组合（归属待实物再次核对） |
| 2 | A31 | 黄色**木质隔热层**，7mm厚为候选，木材材质为用户确认 |
| 3 | A26 | 38×38×5mm加热片候选，放置于木层上侧、金属块底面开腔区域 |
| 3 | A27 | 测温接点候选，靠近加热片上表面并沿金属块独立槽口向后出线 |
| 4 | A07 | 银色12mm金属吸附块；顶孔→内部竖向吸气孔→横向埋置气道→后向接头 |
| 5 | A07W | 独立样品片（照片中对应位置尚需确认） |

**实体层高不变**：自A32底面算起黑9 + 木7 + 银12 = 28mm，现有样品块顶部全球坐标109.2mm（面包板顶面以上89.2mm）未被加厚。A26/A27容纳在A07底部的凹槽内，但从爆炸树看处于木层之上、金属层之下。

## 气路约束
A07内部钻孔和金属本体**属于同一个刚性装配零件**；内孔不存在独立平移、旋转或独立爆炸偏移。A28连接头与A07使用相同爆炸偏移。只有A29为外部柔性软管，随整套样品台移动而形变；分解视图中隐藏柔性电缆和外部软管，避免错误跨接。

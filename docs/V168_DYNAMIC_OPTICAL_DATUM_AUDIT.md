# V168 · 动态光学工作位与静态装配基准解耦

V167浏览器探针证明真实A08壳体底面和A18接座顶面均在世界Y=253mm，真实间距0mm。浏览器断言却错误地规定绝对高度为235mm。原因是显微镜在该工作位上升18mm，不能把静止CAD基准直接当成动态世界坐标。这个失败不是另一次机械穿模。

修正：浏览器回归要求三个OEM壳体网格真实存在，两个端面高度数值有效、彼此相等，真实面间距为0mm。CAD静态A18T顶面/A08底面235mm仍由独立CAD布尔验证。实体、光路和装配位置均不改动。

未解决：A18T接座与TTL200-A下端SM2外螺纹的真正转接零件型号、螺钉和安装方式仍未确认，面接触不是实际固定验证。

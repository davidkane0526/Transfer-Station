# V41 · VN-50真空泵照片重建与证据边界

日期：2026-11-04

## 1. 为什么需要重建

V40的B20主体仍是单根带散热环的圆筒，外形与用户上传的照片120、123不一致。实拍能看到黑色多孔泵体、沿泵体长度方向布置的金属拉杆，以及带独立上部结构的泵组件。继续使用单圆筒会造成泵体体积、轮廓和主要可见结构错误。

V41删除旧的单圆筒主体，按照片可见结构重建候选模型。该版本不是原厂CAD，也不把产品目录中的其他厂商型号认定为用户设备的制造商。

## 2. 证据分级

### 实物照片可确认

照片120的铭牌可读出：

- 型号：VN-50
- 电压：220V
- 功率：230W
- 开放流量：53L/min
- 真空度标注：680mmHg
- 重量标注：约4kg

照片120/123还支持黑色多孔主体和金属拉杆等外观特征。泵端吸入口在整机上的准确位置、朝向和接口形式不能仅凭现有照片确认。

### 同型号族目录候选

一份YCZX产品目录的VN-50表格给出：

| 参数 | 目录值 |
|---|---:|
| 外形尺寸 | 200×110×150mm |
| 安装孔距 | 142×96mm |
| 接口 | G1/4 |
| 电压 | 220V |
| 功率 | 230W |
| 流量 | 53L/min |
| 压力 | −88kPa |
| 重量 | 4.45kg |

目录PDF：[YCZX Product Brochure – Oil Free Vacuum Pump](https://shopcdnpro.grainajz.com/466/upload/down/ba19c1599a297554af95d1a860578437cc7e4471eacf1826c2d370c8d75ea190.pdf)。

目录中−88kPa约等于660mmHg，与照片铭牌的680mmHg相差约20mmHg（约2.7kPa）；重量4.45kg也与铭牌约4kg的标注略有差异。目录可能对应同型号族的另一版本，因此本项目只借用其外形和安装孔距作为候选比例，不据此认定制造商、实际压力性能或原机接口。

## 3. V41几何内容

网页模型和CadQuery STEP按同一名义外形重建：

1. 200×110×8mm候选底板。
2. 四个安装脚，按142×96mm候选孔距布置，候选通孔Ø6.2mm。
3. 黑色电机外壳及部分外露的圆形电机主体。
4. 左端风罩。
5. 两个竖直泵头、顶部盖件及连接桥。
6. 两根沿泵体长度方向布置的金属拉杆。
7. 电机壳体上的照片拟合通风孔。
8. 单独的B20I候选吸入口。其所在侧面和朝向仍未由照片核实。

泵体包络为200×110×150mm候选值。网页端坐标映射为X=长度、Y=高度、Z=宽度；STEP端对应X=长度、Y=深度、Z=高度。

## 4. 自动验证

V41 CAD检查包括：

- B20包络尺寸200×110×150mm；
- B20候选安装孔距142×96mm，四个Ø6.2mm孔贯通；
- B20各结构合并为一个连通STEP实体；
- B20I吸入口保持独立，不与B40软管形成实体堵塞；
- B20不与B01面包板、B22 LED适配电源或B36控制机箱发生候选几何干涉。

B平台总装为81个STEP实体。B20本身为一个连通实体，B20I吸入口单独计为一个实体。上述结果是当前代理几何的一致性检查，不等于真实泵体的制造尺寸或安装验收。

## 5. 尚待实物核验

1. 泵体外形的实际长、宽、高及安装孔中心距。
2. 泵端吸入口的真实侧面、方向、螺纹及密封形式。
3. 两根拉杆的实际直径、端部固定结构和预紧方式。
4. 泵体通风孔的准确数量、孔径、孔距和内部风道。
5. 泵脚与底板的实际接触面、减振垫及固定螺钉。
6. 实物铭牌680mmHg与同型号族目录−88kPa之间的版本差异。

因此V41适合用于装配关系展示和后续测量配准，不能直接作为泵体加工图、采购型号确认或真空系统安全验收依据。

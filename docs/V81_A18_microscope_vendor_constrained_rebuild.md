# V81 · 平台 A A18 显微镜厂商候选与照片约束重建

## 1. 触发原因

V80已经解决平台A的整支路方向、玻片、短边夹紧螺杆、A15悬空控制件和A15+A03竖向尺度，但真实浏览器截图仍显示A18显微镜主机像一个过大的规则黑方盒。该外观不能继续视为完成的逆向模型。

## 2. 厂商检索结论

### Thorlabs MGZ30

Thorlabs历史官方目录显示MGZ30为Post-Mountable Manual Focus Block，具有30mm Z轴行程、同轴粗/细调焦、Ø1.5英寸立柱安装和五物镜转换盘。该架构与照片191–193存在相似处，但现有照片没有可读Thorlabs标识、MGZ30型号、五孔接口或足以唯一对应的立柱夹持细节。

因此V81只把MGZ30列为**候选拓扑对照**，不复制其机械图尺寸和孔位。

参考：
- https://www.thorlabs.com/images/Catalog/V21/V21_8_Imaging.pdf

### 基座光学 MCT-LMP2

厂家资料给出MCT-LMP2：
- 211.5×130×58.8mm
- 40mm升降行程
- 2μm分辨率
- 前面板16处M6和3处Ø10.5通孔

该尺度和前板孔阵均未在照片191–193中得到支持，因此V81明确标记为**排除直接身份**，不将其外形或孔位套入A18。

参考：
- https://www.oeabt.com/show.php?id=674&q=

## 3. V81 A18几何重建

不声称厂商身份，只依据照片中稳定可见的拓扑修改：

1. 主体不再使用单个92mm宽黑方盒，改为三段阶梯壳体：
   - 下段宽70mm
   - 中段最大宽84mm
   - 上段宽76mm
   - 候选深度88mm
   - 总高度70mm

2. 后安装面仍保持在原Z=-44场景基准，使A10支撑臂继续与A18接触，不允许出现悬空或互相穿透。

3. 左右调焦结构都重建为：
   - 主体
   - 调焦轴套
   - 粗调轮
   - 微调轮

4. 自动验收要求两侧三处连接均连续。WebGL探针直接测量间隙，STEP用实体交叠/距离检查验证。

这些壳体和手轮尺寸仍为C级照片比例候选，不是厂家尺寸或加工尺寸。

## 4. A19物镜识别边界

照片191–193的小尺寸预览只能支持局部品牌/系列文字。V81撤销旧版把模糊字符直接写成“10×/0.40”和“5×/0.10”的做法，改为：

- Olympus/Evident PlanFL family?，精确SKU/倍率/NA待核
- JH-TOP MPLAN family?，精确SKU/倍率/NA待核

左侧外倾和中央工作位近竖直的空间关系继续保留，因为这一关系由照片直接支持。转换盘实际孔数、节圆、物镜螺纹和真实工作距离仍未验收。

## 5. 与此前版本的连续性

V81不撤销V79/V80已经确认的关键纠错：

- 膜侧整支路刚体旋转180°
- 玻片为实际转移模型的必需部件
- 两枚夹紧螺杆轴线平行玻片26mm短边
- A15悬空中央圆柱控制件删除
- A15测微组件连续连接
- A15+A03采用同部件厂家组合126mm参考高度包络交叉校核
- A05折腿87.6mm为保持接触面的派生候选
- A11 MWWHL4按Ø30.5×60.1mm、SM1内螺纹深6mm原厂数据建模

## 6. 仍需的关键证据

要把A18从C级照片复原升级到P/D级，需要：
- 主机任一面的高清铭牌或Logo
- 调焦轮侧面及后安装面高清照片
- 转换盘上视/下视高清照片
- A18与A10支撑臂真实连接孔或夹具
- A19两支物镜完整铭牌

如果后续照片能明确看到五孔转换盘或Ø1.5英寸立柱夹持结构，再重新评估MGZ30；在此之前不得把候选写成已识别型号。

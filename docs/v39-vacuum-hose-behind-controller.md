# V39 · 真空软管绕过B19温控器背后（2026-11-04）

## 本次修改

按用户要求，B40 不再从 B36 电控箱上方横跨温控器正面，而是绕到 **B19 宇电 AI 温控器背面一侧**。由于 B19 安装在 B36 前面板上，其背侧位于电控箱内部，因此软管不直接穿入箱体，而是从机箱左侧绕到后方，再沿后侧外部绕过右侧，最后连接 VN-50 泵的候选 INTAKE 口。

## 路径关系

三维查看器坐标为 X 水平、Y 竖直、Z 前后，负 Z 为设备后方。B36 候选包络为 X=222.5–507.5 mm、Y=0–125 mm、Z=−262.5–−37.5 mm。B19 位于 B36 前面板，候选包络为 X=305–425 mm、Y=20–100 mm、Z=−37.5–−19.5 mm。

B40 路径从 B15 后侧接头开始，先从 B16 显微镜立柱右侧通过，再从 B36 左侧绕行；随后沿机箱后侧 Z=−275 mm 通过，继续绕过机箱右侧 X=520 mm，最后从泵的右侧接近 VN-50 候选吸入口。这样软管位于 B19 温控器背后，不穿越 B36 电控箱内部，也不与 B37 加热双线、B38 测温反馈线合并。

## 几何验收

- B40 与 B36 机箱实体不相交，路线从机箱左侧、后侧和右侧绕过。
- B40 与 B19 温控器实体不相交，且确实经过温控器/机箱的后方区域。
- B40 与 B16 显微镜立柱保持间隙；单元测试覆盖样品 X 平移 ±12.5 mm、旋转 ±30° 的组合边界。
- B40 保持中空连续管壁，并连接 B15T 与 VN-50 候选吸入口。
- CAD STEP 和 Three.js 查看器共用相同名义路径节点。

## 未确认事项

VN-50 铭牌型号及铭牌参数来自照片120；但泵原厂品牌、实际吸入口朝向、接头牙型、软管内外径、最小弯曲半径、固定夹位置均未由实物测量确认。B40 的 OD Ø7.0 / ID Ø4.4 mm 仍为建模候选。该路线是按用户要求修正的工程布线方案，不应误称为照片已完整证明的原厂布线，也不能作为真空密封和电气安全验收依据。

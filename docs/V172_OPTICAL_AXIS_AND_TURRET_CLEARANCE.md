# V172 · A19两物镜光轴及转盘真实干涉修复

## 问题来源：本地CAD零件间布尔体积检查

V171默认工作姿态中：A08/A18光轴在X=78mm，A19两个安装孔在X=60mm和96mm，**无任何一个物镜与管镜同轴**。A19N的中心Ø36实心柱将通光轴完全挡住；A18AD穿入旋转转盘的体积约1658.4mm³，A18VR也与转盘相交约39.9mm³。此前966项验证并未检查这一连续光路，是测试盲点。

## V172几何修复

- 将右侧竖直（当前工作位）物镜保持在光轴X=78mm，左侧斜放物镜移到X=42mm，盘体中心X=60mm；直径Ø72及两孔距36mm为现有照片比例候选。
- A19N从实心圆柱改为Ø36/Ø24mm真实贯通环形连接颈，位于A18N Ø48/Ø36.2mm接座内，保留候选径向装配间隙。
- A18AD原Z=163.5..168.5mm与盘体Z=155..165mm发生穿模。修为Z=165..170mm，深度Y=18.5..41.5mm，给±11.8mm候选通光孔留净空并保持到连接桥的机械接触。
- A18AD再退至Y≥18.5mm以避免侵入A19N环形转轴；A18SB右移1mm消除15mm³小型穿模；A18VR原Z=164..234mm侵入转盘1mm，改为165..234mm。
- 增加CAD 10.5mm半径轴向探针，必须实际穿过A19盘体、A19N环和A18N接座；检查适配块、立柱与转盘实体不相交。
- A10立柱按照片191–193从亮银色改为深色视觉候选，不据此认定原厂表面处理。

## 未验证的物理问题

真实转盘到底有几孔、两孔间距、旋转轴/承载轴承、连接颈固定方式以及倾斜物镜是否为另一个固定镜位，均不能从低清照片确认。当前修复消除明显物理矛盾，**不声称盘体已能真实旋转换位**，也不能用于加工。A10/A18整体OEM身份与后支撑接口仍需高清实物和原厂资料。

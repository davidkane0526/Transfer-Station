# V167 · A08/A18 真实实体面接触修正

## 浏览器回归揭示的问题

V166移除A08下端的实心绿色装饰片后，浏览器回归发现真实OEM壳体底面与A18顶面相距1mm。V165测试只读取整个A08 Group包围盒，绿色装饰片比真正的管镜壳体低1mm，恰好掩盖了这一错误。

## 修复

- A18T在CAD中占Y=227..235mm，但旧网页的同一接座位于Y=226..234mm。V167把网页A18T上移1mm，使两个渲染端的基准均为Y=235mm。
- 浏览器审计只读取带A08OEMShellSegment标签的三段真实网格，不再把装饰和标签算进机械接触。
- 增加断言：OEM壳体网格数量为3、A08实际底面世界Y=235mm、A18顶面世界Y=235mm、两者间距为0mm。
- 原厂管镜Ø55.9×28mm、双3.2mm SM2端段及A14候选63.2mm均不变。CAD修订号统一为V167。

## 仍未认证

面接触不是机械固定。A18T与TTL200-A外螺纹之间真正转接件的型号、孔系和安装方式仍未知；没有可依据的制造级尺寸。A10/A18支撑架分件边界也仍未解决。

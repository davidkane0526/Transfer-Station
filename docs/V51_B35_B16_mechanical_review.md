# V51 机械复核记录：B35 / B16

## B35：MB2530/M孔系候选

官方Thorlabs MB2530/M规格与照片中的THORLABS标志、250×300mm板面及25mm网格相符。官方候选参数为：
- 外形：250×300×12.7mm
- M6贯通螺纹孔：25mm网格，首孔中心距边12.5mm
- 四角安装沉孔：共4个，距相邻边25mm；**MB2530/M 250×300mm规格没有中央第五沉孔**。第五孔适用于部分更大型号，不能套用到本板。

实物板厚照片拟合约12mm，因此CAD暂保留12mm，不将MB2530/M写成已确认SKU。按B01候选25mm网格反推，B35中心X=75mm时，四角安装孔位于X=-25/175mm、Y=±125mm，可与B01候选网格配准。B35内部网格共10×12=120个M6孔，CAD用Ø5mm tap-drill proxy表示贯通螺纹孔。

## B16显微镜脚座

脚座仍按65×65×12mm自制转接件候选处理，四个Ø6.5mm通孔构成50×50mm方形。脚座中心调整为(87.5,-112.5)mm，四孔坐标为：
- (62.5,-137.5)
- (62.5,-87.5)
- (112.5,-137.5)
- (112.5,-87.5)

四孔均与B35的12.5mm边缘相位M6网格重合。CAD紧固件同步改为M6×20，穿过12mm脚座后名义进入B35约8mm；这只是几何/长度候选，未验证螺纹啮合与承载。V45采用的(90,-100)mm中心，在正确网格相位下产生约12.75mm错位。显微镜柱仍保持与光轴独立的支撑偏置；支撑臂向柱侧移动以保证与立柱的几何搭接。

## 验收边界

本次修改是照片与厂家孔系驱动的几何候选修订，不等于实物验收。仍需确认B35确切SKU和厚度、B01螺纹与有效牙深、B35沉孔方向、B16脚座实际尺寸及螺钉等级、显微镜支撑臂到镜头组件的接口，以及VN-50泵端接口。

- MB2530/M 250×300mm版本为四角安装沉孔，不含中央第五沉孔；CAD、浏览器模型、BOM与验证报告统一记录4孔。
- B16脚座新增四枚M6×20候选螺钉。按12mm脚座厚度，名义进入B35约8mm；螺纹强度、扭矩和承载仍未通过实物验收。

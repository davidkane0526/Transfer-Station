# V34：照片150中黑色Thorlabs板覆盖显微镜和旋转台的装配校正（2026-11-04）

## 为什么必须改

照片145/150明确显示样品旋转台 B08 和显微镜立柱所在的后方安装区域属于同一块黑色Thorlabs孔板。V32–V33模型B35只有 180×150mm 候选矩形，右后方显微镜底座 B16A 却直接位于下层银色公共光学板 B01 上，形成**不同底高的错误支承链**。

## 本次模型同步

| 零件/关系 | 修改后 | 未确认事项 |
|---|---|---|
| B35 黑色Thorlabs板 | 从180×150扩为**250×300mm的照片覆盖范围候选**，位置由中心 X=95 调到 X=65；厚度暂保持12mm | **不得冒认为Thorlabs MB2530/M**，其标准参考尺寸250×300×12.7mm，厂家孔位、边距、原机螺纹未实测 |

| 两种输出 | three.js交互、CadQuery独立零件和STEP总装分别同步，网页BOM与证据清单更新 | 仍非原生厂家CAD |

## 实体检查

在独立STEP中，采用微小 0.05mm 方向扰动，按 `重叠体积/扰动量` 估算*候选模型的面接触面积*。最近完成的CAD跑了**243项检查**，测得：

- B35→显微镜 B16A 底座：约 **4107.4 mm²**；
- B35→旋转台 B08：约 **6688.3 mm²**；
- B35 不能侵入左侧 B02 磁座，也不能与银色 B01 下板穿模；
- 两个被承载部件均不得伸出黑色板平面边界；
- 网页新增基于Three.js **真实网格包围盒**的双基座支承校验，不能仅以BOM里存在B35就视为通过。

**这些接触面积只是静态几何代理，绝不代表结构承载能力、螺栓预紧力、全行程无干涉或实际机器尺寸。**

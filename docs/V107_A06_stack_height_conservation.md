# V107 · A06 GCM-1102M 完整堆栈高度守恒

当前照片拟合堆栈从面包板顶面到A07银色顶面为：A16 8 mm + A06 33.2 mm + A02 20 mm + A07 28 mm = 89.2 mm，与照片17/18尺读87–93 mm相容。

若仅把A06替换为GCM-1102M厂家21 mm高度，其余层保持不变，则为8 + 21 + 20 + 28 = 77.0 mm。当前场景与该直接替换之间的精确损失为12.2 mm。相对尺图下限仍缺10 mm，相对上限缺16 mm，相对90 mm中值缺13 mm。

A16 GCM-5306M的8 mm已经同时包含在两套计算中，所以不能再次拿A16解释12.2 mm差值。现有Daheng资料说明GCM-110系列可安装于平移台或光学平台，但没有识别到一个必然存在的标准约12 mm增高适配件。

因此V107继续保留当前33.2 mm照片拟合贡献，禁止仅因Ø66直径吻合就把A06改成21 mm。真实缺失层、A06型号或既有照片拟合厚度仍需原始尺图、拆装照片或实测闭合。

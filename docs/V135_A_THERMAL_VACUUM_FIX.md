# V135 · A平台真空、加热与温度功能模型

根据2026-11-11用户截图反馈，修正了A07仅有三层外壳、没有实际吸气孔、加热片、温度探头以及线束从实体壳体穿出的错误。

- A07维持9+7+12mm三层外廓和原顶面约89.2mm高度，在银色上层建立实体中心Ø1.4吸气孔、后方横向Ø2.2通道、底面38.6×38.6×5.4mm凹腔及独立加热/测温穿线槽。
- A26陶瓷加热片38×38×5mm、A27传感接点均独立建模，可通过“加热台剖视”检查，电源线及反馈线从真实候选接口出线。
- A28中空后向接头连通A07，A29空心负压软管随样品运动，末端接A30有地面支撑的服务接口。A30不是未经确认的真空泵本体。
- 本地CadQuery验证金属布尔贯孔、气道交汇、加热片/探头与腔壁不穿模；Node检查365组运动端点，另对A06高优先级候选±5°范围执行55组Catmull-Rom曲线避碰检查。
- 网页旋转滑条允许更大角度用于几何示意，但超出±5°时明确警告真实运动与软管避碰未经验证。不得把365组数学端点检查当作365组无碰撞合格。
- 内部加热器额定参数、测温元件类型、A实机真空泵型号、接头密封与制造尺寸均未验证。平台B的功能链仅作为结构参考，不直接继承B20 VN-50型号。

相关验证：`tests/a-thermal-datums.mjs`、`tests/a-vacuum-clearance.mjs`、`tests/test_a07_physical.py`，以及浏览器A07功能探针和STEP接口审计。

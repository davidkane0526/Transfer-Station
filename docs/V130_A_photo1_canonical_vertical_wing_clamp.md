# V130 · 平台 A 图1正确朝向与图5夹持结构纠错

## 用户要求
平台 A 的玻片转移台“照片参考”和“工作位”都不对；图1是正确朝向；图2和图3是机构旋转后的侧面，用于帮助恢复三维结构；此前图4中的夹持部件一直不正确，应按图5重建，并且整套转移端方向应朝右。

## 本版修改
1. 图1成为唯一朝向基准。照片参考与工作位共享同一 180° 安装方向，工作位只改变位置和升降状态，不改变硬件手性。
2. 图2/图3作为“旋转后的侧面证据”，用于约束侧面层级和三维拓扑，不再用屏幕左右反推图1的世界方向。
3. 修正此前对螺钉方向的误读：图5显示两根螺杆本身是竖直的；“与玻片短边平行”对应的是两螺钉中心连线。
4. A05 末端上夹板改为 32×26×2.5 mm 候选，并恢复两处竖直通孔；螺钉轴线沿 Y，中心连线沿局部 Z。
5. 删除默认装配中的 GCM-13 大块侧向压板、侧向螺杆座和活动压板。A05C 改为图5直接支持的下夹片。GCM-1302M 仅保留为隐藏厂家对比研究件。
6. 玻片近端移入上下短夹板之间，远端 PDMS 保持在玻片右侧工作端。整个膜侧支路经 180° 安装后朝世界 +X，即 UI 右侧。
7. 因玻片夹持位置改变，膜侧名义 X 从 -82.75 mm 更新为 -60.75 mm；竖腿接触求解由 87.6 mm 更新为 86.1 mm。

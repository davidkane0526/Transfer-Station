# V164 · 发布脚本与 CAD 产物命名修复

## Pages 证据脚本

V163 的浏览器模型回归已通过，但证据图片检查步骤在 Bash 解析阶段失败。原因是 V157 图片文件名后有两个反斜杠，导致续行符被转义，下一行文件名被当作意外 token。

V164 将其修正为单个反斜杠。图片文件清单、存在性检查和失败即退出逻辑均保留，不跳过证据验证。

## CAD Artifact 版本

CAD 构建成功生成 V162 STEP 文件，但 GitHub Artifact 名称仍硬编码为 V141。新增读取 `CAD_REVISION` 的步骤，并以该值动态命名产物，避免文件内部版本与下载项名称不一致。

## 版本边界

- 网页模型：V163
- CAD/STEP：V162
- 本次只修复 CI 与交付命名，不更改任何实体几何。

# V108 · A10/A18 显微镜后支撑零件边界审计

## 新问题不是“尺寸还差一点”，而是零件可能拆错

V106已经用两个互补视角分别验证：
- 光学侧：A18主体、左右粗调轮、A19转盘均可直接检查；
- 支撑侧：A18主体与A10后支撑均可直接检查。

重新对照Thorlabs MGZ30官方产品图和工程资料后，MGZ30自身包含向后延伸的立柱夹持壳体，并直接安装到Ø1.5 in（约38.1 mm）立柱。这意味着若平台A实机A18确为MGZ30，当前模型中独立的A10 34×86×25 mm横臂可能并不是一个独立采购件，而是把MGZ30的一体后壳错误拆成了A10。

## V108处理

本版不改变当前几何，因为照片191–193仅有低分辨率预览，无法看清：
- A10/A18后侧是否存在真实机械分缝；
- 立柱实际直径是否为38.1 mm；
- 后壳是否随焦距机构整体运动；
- 横臂是否有独立紧固界面或独立SKU。

因此：
1. A10与A18继续保留为两个照片拟合实体；
2. 新增A-MICROSCOPE-SUPPORT待核接口；
3. MGZ30仍是条件主候选，但其成立会触发A10/A18重新分件；
4. A10横臂在边界闭合前不得单独采购或加工；
5. 禁止在当前A10横臂之外再叠加MGZ30一体后壳，避免双重结构。

## 闭合所需证据

优先级最高的是A18后侧高清照片。若能同时看到立柱、后夹持壳体和主体分缝，通常就能判断当前A10横臂是否为独立零件。其次是立柱直径尺图和立柱中心到光轴距离。

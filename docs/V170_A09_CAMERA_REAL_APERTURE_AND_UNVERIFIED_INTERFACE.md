# V170 — A09真实光学入口，A14缺少已确认转接件

## 本次可确认的旧模型问题

V169的A09外壳为50×45×44mm实心长方体，而其底端又放置Ø30mm完全实心圆片，恰好遮挡相机的中心光轴。与此同时，A14的Ø52.2mm候选内孔虽然在轴向上接触A09机身底面，但其内壁距离相机Ø30mm候选外环有11.1mm名义径向间隙，没有任何已经验证的机械转接件或正确螺纹啮合关系。旧BOM将同一外壳标记为45×45×40mm也与三维实体不一致。

## 修订

- WebGL与STEP均用50×45×44mm外廓、Ø24.4mm×10mm的真开口盲孔替换实心光轴。机械入口内侧保持不透明，**并非在10mm处声明真实传感器**。
- 明确保留径向不连续量11.1mm，同时把C-mount型号、实机螺纹及转接件安装状态记为未证实。
- BOM新增大恒官方3D图纸目录和Thorlabs原厂螺纹转接技术资料；相机前端Ø30、Ø24.4和10mm都是**照片适配的视觉候选**，不可以当作机加工尺寸。
- 在A09/A14零件详情直接显示缺失的接口证据；网页3D探针实际沿光轴投射射线，确认候选开口不再被实心圆盘封住，且盲孔后端保持遮挡。
- 调整暗色材料金属性与前侧补光，使场景中黑色调焦块的结构和层级更清晰，不改实机尺寸。

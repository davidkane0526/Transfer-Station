# V78 · 平台 B 的 B08–B35 四孔整体安装配准

## 问题与已知证据

- B08 是大恒 GCM-1107M 旋转台，原厂底面安装模式：50 × 50 mm 方形四孔、Ø6.8 mm 通孔，以及 Ø11.5 × 16 mm 沉孔。旋转台无外伸操作手柄。
- B35 在实物照片中为同一块承载样品旋转台与显微镜底脚的 Thorlabs 黑色安装板。当前将其**作为 MB2530/M 候选**建模：250 × 300 mm 面内，25 mm 孔距、边缘 12.5 mm 相位，共 120 个 M6 攻丝通孔代理。其当前厚度 12 mm 为照片拟合，而候选产品官方规格为 12.7 mm。
- B16 显微镜脚座的四孔已在当前候选孔网下配准，但这**不能证明 B08 的独立四孔也同时配准**。
- 当前场景坐标：B08 中心 (82, 0) mm、B35 中心 (75, 0) mm；前者位置是场景拟合，不是测量所得的厂家装配坐标。

## V78 完成的实质校核

新算法不再把四个旋转台底孔各自的最近孔位当成一个可实施的安装方案，而是枚举 B35 的贯通孔网，并检验一组统一的平移 \(\Delta X,\Delta Z\) 是否**同时**让 B08 的四个 OEM 底孔配准。判据还要求直径 94 mm 的旋转台底座轮廓完整留在 B35 表面范围内。

| 量 | 当前场景 / 计算结果 |
| --- | --- |
| B08 四孔间距 | 50 × 50 mm（原厂） |
| B35 网格相位 | 25 mm 孔距；12.5 mm 边缘偏移（型号候选） |
| 当前四孔至最近网格点的最大孔心偏差 | 13.657 mm（模型计算） |
| 恢复四孔一致配准的最小刚性位移量 | 13.657 mm（数学候选） |
| 等距候选中心之一 | (87.5, −12.5) mm，\(\Delta X=+5.5\)、\(\Delta Z=-12.5\) mm |
| 等距候选中心之二 | (87.5, +12.5) mm，\(\Delta X=+5.5\)、\(\Delta Z=+12.5\) mm |
| 当前模型自动执行上述位移 | **否** |
| 实物四孔螺接已确认 | **否** |

注意：表中“最小刚性位移”只是候选孔网下的相位解，**并不是最合理的光学装配位置**。尚未检查该平移对实际显微镜光轴、旋转中心、邻接组件和实物尺寸的影响，因此不会擅自把 B08 移到数学对齐点，也不会新增没有证据的底座螺丝或转接板。

## 网页与自动测试

- 选择 B08 或 B35 的 BOM 项后，在零件详情中显示四孔整体配准问题、偏差和两个最近平移候选，不在默认三维视图叠加干扰性标签。
- `tests/b35-fastener-audit.mjs` 校验当前偏差、两个等距配准解、四孔同时对位、底座完整落板及无可行网格时返回空结果。
- `tests/model-b-visible-smoke.mjs` 检查 B35 明确显示当前全厚通孔，而不是已经废弃的 2 mm 装饰盲孔，并检查详情提示不可自动平移。
- 平台 A 的**默认实物视图仍不包含任何假设玻片、独立候选夹爪或未安装的 PDMS**。这次不修改已由照片194/196校正的两枚蝶形螺钉方向和真实构件层级。

## 仍缺少的实物校准证据

需要 B35 板面孔原点相对实物旋转台底部四孔的对位照片、B08 底座实际螺接/转接结构，以及 B08–B16 的实际光轴相对位置；真实装配固定方案仍处于待验收状态。此阶段的几何候选不得作为采购、加工或承重安装依据。

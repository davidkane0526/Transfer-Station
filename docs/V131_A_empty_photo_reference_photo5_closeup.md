# V131 · 平台 A 空载照片参考与图5专用近景

## 用户证据优先级

本轮继续沿用 V130 已确认的方向关系：

1. 用户图1是平台 A 的基准朝向；
2. 图2、图3是同一机构旋转后的侧面证据；
3. 图5直接约束 A05 夹持端；
4. 用户此前明确指出：照片参考图中不应出现长玻片，但工程建模必须保留玻片，并在工作位使用。

因此，“照片参考”和“工作位”共享同一物理手性，但不是同一装载状态。

## V131 状态定义

### 照片参考

- A05、A05C、A05CS 保持可见；
- A05G（76×26×1 mm 候选玻片 + PDMS）隐藏；
- 不改变 V130 的 180° 安装方向；
- 膜侧 X/Y/Z 运动控件冻结，避免用户拖动后仍把该状态误认为照片对照；
- 状态栏明确显示“空载，无玻片/PDMS”。

### 工作位

- A05G 恢复可见；
- 玻片近端进入 A05 上夹板与 A05C 下夹片之间；
- PDMS 位于远端并对准 A07；
- 膜侧 X/Y/Z 几何运动预览恢复；
- A05 两枚蝶形螺钉继续保持竖直螺杆和上扬蝶翼外观。

## 仍未确认

以下内容继续保持候选，不因视觉接近而升级为实测：

- 玻片实际插入深度；
- 两螺钉真实孔距、螺纹和螺距；
- 上/下夹片真实厚度；
- 图5夹具 OEM 型号；
- 蝶翼精确角度。当前约 33.2° 只用于匹配照片外观；
- 夹具下方可见小型突出件的功能和尺寸，未获得足够证据前不新增功能定义。

## CAD 边界

STEP 继续保留工作位完整玻片/PDMS，因为 CAD 的目标是完整转移装配，而不是复刻“拍照时未装玻片”的瞬时状态。空载状态属于 WebGL/证据视图的可见性状态，不删除工程零件。

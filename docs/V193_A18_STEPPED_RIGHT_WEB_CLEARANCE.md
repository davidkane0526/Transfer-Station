# V193 · A18 右侧固定网阶梯式连接与活动立柱避让

日期：2026-11-17。

## V192 验收发现

V192 将整块右侧固定网向左移动 3mm，修复了它与偏置机身之间的 2mm 断缝，但 CAD 随后发现右侧固定网侵入活动光学立柱。不能以修复静止件连接为代价破坏活动件的运动净空。

## V193 结构修正

右侧固定网拆分为一个连续的阶梯式截面，而不是简单平移整块零件：

- **主网片**：恢复 V191 的坐标，继续位于 +X/照片右侧，并与右侧固定导轨 A18G2 保持搭接。
- **后下连接脚**：从主网片向左延伸 4mm，在后下区域与偏置后的 A18 机身形成 1mm 实体搭接。
- **活动立柱避让**：连接脚位于活动立柱的后下方，主网片仍保持与活动立柱的 1mm 候选横向净空。

## 左右方向约定

WebGL 参考视图从 +Z 正面观察，屏幕右侧为 +X。STEP 正面从 +Y 观察、+Z 向上，屏幕右侧为 -X。V193 的阶梯式固定网轮廓在两个坐标系中表示同一物理结构；V194 对 STEP 的 A18 零件族执行镜像，以保持投影方向一致。

## 验收

- 右侧网片与连接脚必须合并为一个有效 STEP Solid。
- 两侧固定网分别与偏置机身和对应导轨实体连接。
- 活动光学立柱不得与右侧固定网发生实体干涉。
- 左右固定网的 X 坐标顺序必须与 +Z 照片视角一致。
- 照片拟合尺寸仍未实测，不作为加工图。

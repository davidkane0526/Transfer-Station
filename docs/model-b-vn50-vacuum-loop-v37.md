## 2. 应有的功能性连接次序

1. B11 上表面单中心 Ø1.4 mm 真空吸附孔（孔径候选，单孔数用户确认）
2. B11 内部水平空气通道，延伸至金属块后侧 −Z（候选结构）
3. B15 真空管接头：真正钻空的轴向管芯，去除早期堵住气路的实心圆柱代理
4. B15T 后侧短管：中空环形软管实体，与B15后端对接
5. B40 外部长负压软管：真实中空几何，从热台后侧沿设备外部弧形绕行
6. B20I VN-50 进气端候选：真实中空环形吸入口；B20 为泵整体机身

此回路与 B37 加热器双线、B38 温度反馈线完全分开，**不进入 B36 宇电温控器电控箱**。真空泵电源和控制回路未从现有照片识别，不画虚构电路。

## 3. 空间路由与运动

- 浏览器工程坐标为 X（左右）、Y（高度）、Z（前后），mm；CAD 高度对应第三维。
- 旧 B15 后侧短软管末端在候选位置 (94, 90.5, −79) mm。
- 新B40从该点连续延伸，先向后上方绕过显微镜立柱，然后从电控箱上方经过，最后从泵体前上方绕到外侧的候选吸入口 (425,68,180) mm。
- 对于 VN-50 原始实物泵的接口方向，照片仅提供标有 **INTAKE** 的吸气方向提示；**场景中所画接口位置仍为布局候选，非OEM坐标**。
- 浏览器 `refreshVacuumHoseB` 在样品台 X 平移、绕 Y 旋转时更新第一段软管路径，泵固定端不动；路径控制点采用管路应力与碰撞初筛，不代表完成了全行程弯曲应力或气密性认证。
- B20 外壳照片候选加了冷却肋片、真实空心吸入口，其他外形及定位孔需要实物原生 CAD 复原。

## 4. 验收与剩余风险

V37 的 `cad/validate_interfaces.py` 增加了：
- B15 的轴向 **真实空孔** 探测；
- B15T、B40 的中空中心轴穿透探测，避免将实体管误画成“真空软管”；
- B20I 与泵头的开放进气通道探测；
- B40 不穿过 B36 控制箱金属壳、B20 泵体或 B01 光学面包板的实体干涉检查。

浏览器 `window.__modelBVacuumProbe()` 与 `tests/model-b-visible-smoke.mjs` 将验证模型铭牌、真实开放端口、两层管壁、B15短管末端与B40首节点的重合、B40与泵候选进气端的重合，并在样品平移/旋转后再次测试端点连通。

**保留未验收项目**：泵吸入口真实方位、接头G1/4牙型、软管ID/OD、内置止回阀/泄压阀/真空过滤器是否存在、软管耐温/固定夹具、真空泵供电控制、动态连续真空密封及每个运动组合下的软管无干涉。

禁止把此模型直接用作真空泵实际接线、采购软管或加工真空接头的最终图纸。

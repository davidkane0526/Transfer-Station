# V44 · B15–B40–VN-50 真空接口配对审计

日期：2026-11-04

## 本轮发现

V43 已把 B11 中心吸附孔经 B15、B15T、B40 的**中空候选管路**绘制至 VN-50 的 B20I 候选吸入口，并完成避让温控机箱、线束及运动姿态的几何检查。但“管路中心线连到泵口”并不等于“两个接头能直接安装并密封”。上一版虽显示了孔径，却缺少直径配对校验。

本轮不凭空加入实物中尚未识别的变径接头 SKU，也不更换已标注为候选的尺寸，而是通过程序对两端的名义尺寸关系建立明确的风险标记。

## 候选尺寸与配对检查

| 接口位置 | 当前模型候选值 | 配合结果与证据边界 |
|---|---|---|
| B11 吸附孔 | Ø1.4 mm | 仅模型候选，用户确认单中心孔，不代表实测孔径 |
| B15 后侧接头 | 外径 Ø6.0 mm，内孔 Ø2.84 mm，长13mm | B40内径 Ø4.4mm 若直接套入外径Ø6.0mm接头，内径名义增幅约 **36.4%**；能否使用取决于真实管材弹性、倒钩、卡箍及气密性，当前未验证 |
| B40 柔性软管 | 外径 Ø7.0 mm，内径 Ø4.4 mm | 壁厚名义1.3mm，均是模型候选 |
| B20I VN-50候选吸入口 | 外径 Ø18.0 mm，内孔 Ø8.2 mm | B40内径若套入候选外径Ø18.0mm，直径名义增幅约 **309.1%**，不能默认直接套接 |
| 泵孔与软管外壁 | 孔Ø8.2mm / 软管外径Ø7.0mm | 若把软管末端直接插入名义孔，会留有 **1.2mm直径间隙**，不能当作已密封接口 |

注意：所谓Ø18.0mm泵口尺寸来自当前绘制的 B20I **候选外形**，不是 VN-50 实物泵口厂家测量；同型号族宣传材料的 G1/4 接口并不能证明当前泵体的接口型式、牙型或安装朝向。

## V44落实的检查

- `src/pneumatic-dimensions.js`：对 B15、B40、B20I 的外径、内径及名义配比自动计算，明确 `directFitVerified=false` 和 `sealedVacuumCircuitVerified=false`。
- `tests/pneumatic-dimensions.mjs`：回归测试防止未来仅因绘制了贯通气路而宣称已完成接头配对。
- `src/app.js`：在选中 B15/B40/B20 等关联部件时，显示接口风险及所有候选尺寸。默认三维视图不新增遮挡标签。
- `tests/model-b-visible-smoke.mjs`：浏览器实测选择B40、B20时必须显示“真空接口装配尚未闭合”，并验证模型探针不宣称真实密封。
- `cad/validate_interfaces.py`：向STEP验收结果写入未解决的软管/泵端接口配合状态。该风险不应通过假定厂商配件或隐藏检查消除。

## 后续实物必须取得的参数

1. VN-50 实物 **INTAKE** 吸入口的具体位置、接口照片、外径/内径、内外螺纹及牙型。
2. B15 后侧实物接头的外径、倒钩结构和可夹紧长度。
3. 真空软管实际内径、外径、材料牌号、最小弯曲半径、耐温和负压额定值。
4. 实际使用的泵端变径接头或转接件及密封方式。如果需要采购新转接件，应先从测量数据确定规格，不能直接把模型中的Ø18mm认作标准管嘴。
5. 两端卡箍/快插/螺纹件的机械固定及负压气密测试结果。

**本轮结论：V44 中空管路的几何可视化和避让检查可以通过，但泵端安装与密封仍未验收。不得将 V44 作为可直接采购装配的真空管路图。**

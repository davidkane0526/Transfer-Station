# V92 · A18 实拍偏心纠错与 MGZ30 证据升级

## 1. 为什么要改主模型

V81–V91虽然逐步修正了A18的粗糙外形和厂商候选，但仍保留了一个错误假设：A18黑色主体、上方相机光轴、下方物镜转盘全部以同一X中心线对齐。

重新直接观察照片191与193后，可以看到竖直相机/物镜光轴位于黑色主体的左侧，主体明显向右展开。因此这不是“厂家型号尚未确认”的问题，而是当前几何本身需要纠正。

## 2. V92实体改动

- 光学轴：保持原位 local X = 0。
- A18主体中心：向右移动24 mm。
- 84 mm主体左边界：local X = -18 mm。
- 光轴在主体宽度中的归一化位置：(0 - (-18)) / 84 ≈ 0.214，即从左侧约21.4%位置穿过。
- A18前面板、左右调焦hub/coarse/fine旋钮：随主体整体右移24 mm。
- A18顶部/底部光学接口：不移动。
- A19转盘与两支可见物镜：不移动。
- A11 MWWHL4：场景基准从光轴+72 mm同步改为+96 mm，以维持与右调焦链原有相对间距。

24 mm不是实测尺寸，而是当前低清实拍的比例拟合候选。自动测试明确要求 `photoBodyCenterOffsetMeasured=false`。

## 3. MGZ30为什么升为主候选

Thorlabs MGZ30原厂资料确认：

- 黑色封闭式调焦主体；
- 30 mm Z行程；
- 粗/微同轴调焦；
- Ø1.5 in（约38.1 mm）立柱安装；
- 内置五孔物镜转盘；
- M26×36 TPI物镜接口；
- 上部dovetail可集成30 mm cage、SM1和SM2。

平台A已经存在较强的Thorlabs系统证据：A08为TTL200-A，A11为MWWHL4，A14正在使用SM2接口候选。这使MGZ30不仅“长得像”，而且在整个光机生态上也更连贯。

## 4. BXFM-F为什么降级

BXFM-F机械图仍然很有价值：84 mm宽、Ø32H8立柱孔、后侧4-M8接口和30 mm行程都与场景尺度相容。

但原厂实物是明显银色开架/铸件结构，前后存在大量开放减重区，而照片191–193中的A18是黑色封闭块。这一视觉冲突比单纯84 mm宽度吻合更有区分力，因此V92把BXFM-F从并列高优先级降为次候选。

## 5. 仍然不做的事情

- 不把A10立柱直接从Ø26改成Ø38.1，因为现有照片没有尺图。
- 不把A19强制改成五孔转盘，因为低清照片只支持“两支已安装物镜可见”，无法确认总孔数。
- 不把MGZ30工程图中的总包络直接映射到当前XYZ轴，因为当前装配方向尚未由厂家CAD与实拍共同锁定。
- 不把MGZ30写成“已确认型号”。

## 6. 新增硬约束

1. A18主体中心相对光轴必须保持+24 mm候选偏置。
2. A18T/A18N上下光学接口中心必须继续落在原光轴。
3. A10后支撑与偏心后的A18仍需保留实接触，不允许产生悬空。
4. A11随主体偏移后不得与右侧调焦hub/coarse/fine发生穿模。
5. MGZ30仍为candidate only，`MGZ30GeometryApplied=false`。

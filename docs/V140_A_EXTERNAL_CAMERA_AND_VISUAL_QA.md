# V140 · 平台 A 外设自动取景与可见性硬性验收

V138-V139 的 A30 泵、A33 PID 温控箱和 A12 LEDD1B 已存在，但当前实际生成的外设截图有明显屏幕裁切。这是取景质量缺陷，不应被“BOM中存在零件”所掩盖。

新增 `src/a-external-camera.js` 独立计算摄像机位置，输入 A07、A12、A29、A30、A33 的实际三维包围盒8个顶点、相机垂直FOV、窗口纵横比与安全边距。B平台保持原样。界面增加“ A 泵·控制器 ”视角，用户可一键同时查看泵、温控箱、LEDD1B和负压软管。

新增 `window.__AExternalCameraFitProbe()` 并由浏览器回归使用真实 `Vector3.project(camera)`，直接拒绝任何一件关键外设被裁切的场景；同时生成 V140 截图并放入对照页。五种窗口比例数学测试独立于WebGL已在本地运行通过。

A30的VN-50同族外形只是候选；温控器电气端子、真实泵型号和A10/A18显微镜原厂安装边界仍需实物证据。不要将视角改善理解为OEM完成验证。

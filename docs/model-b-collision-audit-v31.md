# V31：B 平台实物—网页—STEP 统一排查（2026-11-03）

本次只处理用户此前连续指出的模型 B 差异。对照实拍 **108 / 149 / 150** 与 V30 浏览器截图，并将 `Transfer-Station-V30-Side-Mount-CAD.zip` 中独立零件 STEP 导入 CadQuery **逐对求几何相交体积**，而非只比较包围盒。

## 发现与修正

| 对象 | V30 实际发现 | V31 处理 | 证据等级 |
|---|---|---|---|
| B04A 固定竖直机架 vs B04C 竖直测微杆 | 实体重叠 **1455.7 mm³**。一根银色螺杆竟穿过没有孔的固定金属机架 | 测微轴移到立式导轨**左侧外面**，增加带 Ø13.2 真实通孔的薄支承环 B04G，短连接桥贴合固定机架；轴和环留 0.1mm 径向显示间隙 | 实拍外置关系 P；尺寸 C |
| B06 固定主体 vs B06F 固定夹面 | 独立 STEP 实体重叠 **70 mm³** | 修正固定主体侧壁，两个部件在侧面清洁接触，不再有重叠体积 | 结构推断 I；尺寸 C |
| B06 固定主体 vs B06M 活动压力板 | **490 mm³** 体积穿透。活动压板不能在固定金属内部正常滑动 | 移动板不再侵入主体，重新保留一块共用移动压板和两颗压力螺杆 | GCM-13 产品工作机理 D；本体位置 C |
| B04E V25M 正面 | 错误的整块大面积银色无孔平板，与照片108/149正面的黑色带孔导向件不一致 | 改为黑色移动导向面，提供 **12 个真正 2mm 深的盲孔**，前层布尔/挤出造孔、后层保留实体。示意孔位仅照片拟合，**非原厂孔系图** | 实拍外观 P；孔位/直径 C |
| B24 PHUC-1 | 网页把同一台黑色万向支架画成上下两个分离的圆环，而 STEP 中是完整 Ø30×60 圆柱 | 网页改为连续圆柱外壳的参数化表面，两个贯穿 Ø12.1 孔在上下间距 33mm 的位置真正打开，外观与 STEP 近似一致 | 厂家外形/孔距 D；壳体接缝和锁紧机构 C |

**这不是原厂加工验收。** V31 只证明新假设的几何避免了上述明显穿模。B04G 的真实厂家零件/安装螺丝、V25M 的固定导向件与活动板配合、B05侧向支承面载荷与螺钉、PHUC-1 内部旋转接合、B26 端部 M6 螺纹/啮合及双杆长度仍未完成物理配准。

## 新的自动验收

`cad/validate_interfaces.py` 新增：

- 对固定导轨、测微杆、带孔支承环、GCM 固定主体、上下夹板进行精确体积相交检查。
- 对 **18 个关键支承/杆架/玻片夹实体**执行成对干涉扫描。已知不需要实体穿透的接口不设置忽略名单；允许实体面接触，拒绝非零相交体积。
- V25M 黑色前面板的 12 个候选盲孔须前侧开放、背面仍有实心材料，不能错误钻成贯穿孔。
- PHUC-1 Ø30×60 外廓、两根独立 Ø12 横杆孔的 33mm 孔距，以及 B28 下层杆端和 B06 侧面接口继续由原有 QA 保证。
- 网页浏览器回归检查仍须包含 B08–B23 样品台、热台、显微镜、真空和辅助系统，不能再次只输出玻片位移机构。

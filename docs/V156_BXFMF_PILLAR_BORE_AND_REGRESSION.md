# V156 · BXFM-F 立柱孔连续性与回归修复

日期：2026-11-13。

## 修复内容

1. BXFM-F 对照模型的 Ø32H8 立柱孔现在贯穿主体、底部安装板和顶部盖板，不再只是底板上的浅孔代理。
2. 原厂图纸没有给出该孔的有效深度，因此模型只表达连续孔道，不声明有效插入深度、夹紧方式或与当前 A10 立柱的已验证配合。
3. 修复候选说明中的型号识别边界文字，保持“尺寸吻合不能证明型号”的原有要求。
4. 将 Transfer-Station-A-V155-BXFMF-Drawing-Study.png 加入 CI 的 A 工程证据与预览附件列表，便于直接检查对照视图。

## 验证要求

- 4 个 M8 后安装孔、4 个 M4 后辅助孔、4 个 M4 底部安装孔仍保持独立计数。
- 2 个粗调旋钮与 2 个微调旋钮仍保持双侧配置。
- 研究视图默认隐藏，不改变 A18 默认照片拟合几何。
- 关闭研究视图后恢复默认 A18、A10 支撑及 A08/A19/A20 可见性。
- 模型仍标记为图纸对照重建，不是原生 STEP，不代表实机型号确认。

**V156 不将 Ø32H8 与当前 Ø26 mm 立柱声明为直接装配兼容。**

# V46 · 平台A的活动机构、磁座与显微镜底座修正审计

> 2026-11-04。**本次仅修正可由当前代码检测出的几何/运动错误并加入大恒厂家型号的候选结构。** 未获得A05玻片夹、A17磁座的清晰型号照片和A两侧在同一坐标基准下的标尺图，不能宣布平台A已真实复原。

## 1. 重新建立 A03 GCM-VC13M 活动端

**旧问题：** V45网页的 `film-drop` 滑杆改变数字，A03顶部输出板、A04摆角台、A05薄L片没有相应的竖直运动。控制标签错误地持续显示B平台的“V25M”，样品标签错误地持续显示B09 NFP。

**V46源码变更：**

- 将A03输出板放入单独 `verticalCarriage`，保留A03固定基体与A15双轴T25M之间的安装关系；
- A04/A05 `moveFilmVertical:true`，随活动板一起下降，避免旧版空中分离；
- 旧STEP的A03顶面和A04位置定义为 **候选下降下限**。网页默认以该位置**向上13mm**作为拟合起始姿态，滑杆从0到-13mm下降到旧静态位置。固定机架代理顶端缩短，以免移动输出板穿入未经开槽的实心机架；
- 厂家GCM-VC13M总行程13mm，但**照片中实际初始行程位置未测量**，不能把该位姿称为实物零位。两侧偏航/末端玻片接触仍未验收。
- 控制页在A切换时显示 VC13M/T25M，在B显示 V25M/NFP；另设A专属不可用状态提示框。
- `window.__modelAKinematicProbe` 和 Playwright 检查增加：A03固定基体保持、活动输出下降6mm、A04/A05同步下降6mm，状态仍为`glassClampedAndReachable:false`。

**运动预览与静态STEP不同：** A网页起始展示的是候选上抬13mm位置，而V46 STEP仍是未加载动态位姿的*下限静态构型*。这只是两种模型姿态，不代表有实物零点标定。

### V46补充：A03竖直微分头与活动板实际间隙

再次检查发现，旧网页中VC13M银色竖直微分头中心位于机构前侧Z=25mm，半径6.8mm的滚花部分与65mm活动上台面的±32.5mm投影重叠。若直接下降，上台面将与测微头发生几何干涉。V46已将测微头的前侧候选安装位置改为Z=40mm，采用两条与固定机架连接的前向支承轨和一只**带真实轴向空腔**的支承环，避免在网页用实心方块包住微分头。

STEP采用A03固定机架 + 独立活动顶板**A03T**（65×65×7mm）的拆件方案，活动板底面在候选下限Z=117mm与固定导轨顶面接触，二者不融合；另将固定连接臂加工为带半径5.8mm孔的候选结构，使半径5.5mm的微分头钢杆贯穿而不相交。该局部代理几何已在独立CadQuery布尔检查中得到：固定机架为1个连通有效Solid，与A03T、测微杆及滚花旋钮相交体积均为0。**完整全行程的厂家CAD碰撞验收仍未执行。**

## 2. A05 / A07 的装配坐标仍然错误

当前代理几何：A15中心X=-116mm，A07中心X=78mm，样品台宽65mm。A05原L片向左的折边端为X=-176到-163mm，热台左缘X=45.5mm。将玻片台/样品台各自最多12.5mm的X行程完全用于靠近，仍差**183.5mm**。

新增镜像试算（**不修改实物模型**）：若将折边相对A15左右镜像，则末端投影为X=-69到-56mm，考虑同样25mm合计相向行程仍差**76.5mm**。故单纯将L片翻向样品也不足以连接，必须修正相对支架原点、真实末端构型及照片观察方向，不能造一根更长的假横梁。

A05下缘在旧静态下限高度为72mm、A07顶面99.2mm，低于热台顶面27.2mm；网页新增抬升预览会改变此高度，**这一差值不是实物工作距离**。

> A05末端玻片夹完整型号/位置未识别，A17磁座安装位置未证实；平台A仍应标为`functionalTransferAccepted:false`。

## 3. A17 磁座：从通用实心方块改为有可检查孔深的候选

大恒厂家目录中 **GCM-420302M** 的已知数据：65×65×20mm、标称30kg吸力、550g。其顶部为 **5-M6、4-M4、4-M3** 候选孔阵列，对应方形孔距50/40/32mm，带磁性开关。现有A照片无法确认实际磁座就是该型号。

V46网页和STEP已按**未确认候选型号**加上相同13处孔位：中心M6+四角M6、四角M4和四角M3，所有视觉孔均暂做**3mm深盲孔**以免冒充原厂螺纹有效深度；新增附在底座一侧的磁性开关代理。

CAD检查逐孔确认3mm上层是孔、下层仍有材料，检查开关与本体实体接触。网页也记录候选孔数量。**不得把3mm可视孔当作30kg载荷下的螺丝啮合能力。**

参考厂家目录：<https://elektronik.tamser.com.tr/CDHC_catalog_VIII.pdf>，GCM-42 Magnetic Bases；当地经销商说明：<https://www.anjun.com.tw/%E5%85%89%E5%AD%B8%E5%85%83%E4%BB%B6/%E5%85%89%E5%AD%B8%E5%85%83%E4%BB%B6%E3%80%81%E5%84%80%E5%99%A8%E9%8A%B7%E5%94%AE/dhc%E5%A4%A7%E6%81%92%E5%85%89%E9%9B%BB/%E5%85%89%E5%AD%B8%E6%94%AF%E6%92%90%E4%BB%B6%E7%B3%BB%E5%88%97/%E5%BA%95%E5%BA%A7/%E7%A3%81%E6%80%A7%E8%A1%A8%E5%BA%A7/gcm-42%E7%B3%BB%E5%88%97-%E7%A3%81%E6%80%A7%E8%A1%A8%E5%BA%A7/>.

## 4. A10 显微镜立柱：从“头上有螺钉、底板无孔”改为候选通孔连接

**旧问题：** V45仅将悬空立柱接到了72×65×14mm实心底脚；网页绘制四枚螺钉头，却未在A10 STEP和网页底脚开相应的贯穿孔。

V46保持立柱基准世界X=78、Z=-112（网页），将底脚外廓中心作候选偏置至X=75、Z=-100（网页），设置四孔世界平面中心 **(50,-125)、(50,-75)、(100,-125)、(100,-75)mm**，对应面包板A01的25mm候选网格。

- 底脚：四个 **Ø5.5mm** 真实候选通孔及头部 **Ø9mm×2.5mm** 候选沉孔；
- 螺丝：独立四枚候选M5紧固件，模型轴/头确实对应孔中心，螺头在底脚上表面名义齐平；
- 检查：CAD孔洞、A01对位孔、紧固件连通性，WebGL射线真正穿过四孔而非靠布尔标记计数；
- **实物仍未验证：** A10底脚采购SKU、锚固位置、面包板是否为对应M5螺纹、有效螺纹深度、预载和支架弯矩。

这是工程候选配准，**不是厂家认可的A10孔位**。

## 5. A16 安装板

实拍能识别 GCM-5306M，其厂家标称112×70×8mm。厂家孔系示意存在13-M6、8-M4、4-M3等布置。但本仓库A16→A01还只是四个Ø6.5贯通孔和M5螺丝的**独立候选方案**，不能说是原厂安装孔，也还没有与A06旋转台的真正螺丝孔完成配准。

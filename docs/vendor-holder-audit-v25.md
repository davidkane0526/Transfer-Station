## 目前的机械结构

正常装配（非爆炸视图）的候选力传递路径：

`B04 GCM-V25M → B05非标安装底座 → B27 PHSP12-1短立杆 → B24 PHCP-2交叉杆夹 → B25 PHSP12-5水平杆 → B26尚未确认的末端转接座 → B06 GCM-13板片夹候选 → B07玻片`

B05仍有4枚底座紧固件图示，但其对应安装孔、螺钉规格、底座材料强度均不确定。B24包含两个几何贯通的Ø12孔，画出分立的正交夹持圆筒与锁紧头，B25采用150mm原厂整数尺寸。B26保留有真实中空套筒与下方转接座，**没有标注不存在的商品型号**。B06显示薄片夹的两处夹持面，但夹持口形状、弹片/夹紧机构的细部仍需原厂图或原机局部照片验证。

对B06，厂家L=60mm只是厂家产品的尺寸参数，此模型暂把它作为背部支撑方向长度代理；未取得与原厂三视图同向比对前，不把这个方向推定当作真实安装方向。玻片厚1mm、夹口1.5mm来自旧版工程候选。

## 未完成的复核

1. **最重要：**在107/108原机照片中，确认黑色Zolix连接块是PHCP-2圆柱对夹、PHCP-1方形正交杆夹还是别的夹持器。
2. 核对实际支杆直径为Ø12还是Ø12.7mm；若是后者，替换整组杆/夹，不是只改数字。
3. 对比玻片侧黑色夹具的夹紧螺钉数、夹爪朝向、弹片、总长，决定GCM-1302M、GCM-1311M或者其他厂家型号。
4. 对照原机近景测出B05/B26的安装面方向、连接螺纹和杆实际受力路径。这两件**仍没有已确认的原厂 SKU**。
5. 按厂家真实CAD/机械图检查全行程光路、玻片与物镜、加热台的三维干涉，完成抗弯变形和夹紧稳定性核算。

# V158 · LYLIGHT FR8425 84mm/25mm 焦块候选研究

日期：2026-11-13。

## 1. 新增厂商候选的依据

LYLIGHT 官方产品页将该产品标为 **FR8425 Focus block mount Size 84mm**，并明确给出：

- 显微镜安装规格：84mm（页面表述为标准 84mm mounting size / focusing bracket diameter）。
- 立柱孔：Ø25mm。
- 导向形式：Ball bearing focus system。
- 传动形式：rack-and-pinion / rack-and-pinion ball-bearing guide。
- 页面描述了粗调焦，但没有发布精调精度、焦程、中心距或完整外廓尺寸。

来源：[LYLIGHT FR8425 官方产品页](https://www.lylight.com/product/focus-block-84mm-25mm-pole-focus-rack-focusing-mount/)

## 2. 为什么把 FR8425 加入 A18 候选矩阵

当前 A18 照片拟合主体最大宽度记录为 84mm（候选值，未尺测）。FR8425 的 84mm 安装规格与这一包络数值相符，同时其 Ø25mm 立柱孔与当前模型中尚未实测的 Ø26mm 立柱候选接近。

这使 FR8425 值得优先进行接口核对，但**84mm 数值相同不能证明型号相同**。FR8425 公开页面没有提供中心距、安装孔位、焦程、精调机构、完整尺寸图或 STEP，因此目前无法把它作为已识别实机。

## 3. V158 三维拓扑对照模型

新增独立的 FR8425 候选视图，包含：

- 名义 84mm 安装环。页面只给出 84mm 安装规格，模型的环壁厚、外径和开口细节均为视觉代理。
- Ø25mm 立柱贯穿孔，按厂商明确接口值建模。
- 双导向轨、四个滚珠导向滑块，用于表示厂商所述 ball-bearing guide 拓扑，内部滚珠结构没有被虚构为已知尺寸。
- 齿条与小齿轮代理，表示 rack-and-pinion 粗调结构。
- 一个粗调旋钮与一个张力调节代理。厂商公开页面没有证明存在独立精调旋钮，因此不把张力调节代理标成微调旋钮。
- 后部连接桥与 112mm 安装距离只用于沿用现有照片拟合位置，**不是 FR8425 厂商尺寸**。

## 5. 模型使用边界

- FR8425 研究模型默认隐藏，只能通过网页“FR8425 84/25候选”按钮查看。
- 不改变默认照片拟合 A18，不改变 A10/A18 零件分界。
- 不将 112mm、环壁厚、导轨间距、旋钮直径、焦程或外廓代理值写成厂商尺寸。
- 当前 191–193 项目内照片仍是 128×170px 预览，无法完成高分辨率接口和分缝复核。
- 在取得 FR8425 原厂工程图/STEP 或 A18 高清后视、侧视和安装接口照片前，不将 FR8425 定型为采购或制造型号。

**V158 的实质进展是补入一个与 84mm 实物包络更匹配的厂商候选，并提供可交互三维拓扑对照；它不是型号确认，也不是原厂 CAD 复刻。**

# V181 · A18 长光学筒与 A09 相机外部硬件补全

日期：2026-11-17。

## 照片对照依据

用户提供的高分辨率显微镜抠图显示：
- A18 主体侧面有一根明显长于安装法兰的水平光学/成像筒，且具有阶梯筒段和环形连接部。
- A09 相机外壳顶部有两根金属柱，侧面可见四个紧固点。
- A18 侧向筒必须与机身侧孔同轴连通，不能只是外表面贴一根空心管。

## V181 修改

1. **A18 水平光学筒**：从原 54mm 候选外伸长度改为 90mm，分为近机身筒段、环形连接段、远端筒段和前端环。内孔保持 Ø19mm 候选。
2. **A18 机身侧孔**：保留位于光学筒安装同侧的真实 STEP 贯通孔，验证从筒端到机身接口的轴向探针不与实体相交。
3. **A09 相机外壳**：新增两根顶部金属柱和四颗侧面紧固件，作为可见实物细节的照片拟合代理。
4. **验收**：浏览器检查侧筒长度元数据及相机紧固件数量；STEP 检查 A09 柱/螺钉实体数、安装位置和 A18 侧筒包络及贯通孔。

## 尺寸边界

- A18 水平筒 90mm 外伸长度、Ø27/Ø28 外径候选，以及 A09 金属柱和螺钉尺寸均为照片拟合值，不是实测。
- A18 内部光学组件、螺纹、焦距及 A09 相机型号仍未确认。
- GCM-5306M 仍对应 A16 支杆安装底座，不是 A06 旋转台。
- 该模型用于装配关系审查，不作为加工图。

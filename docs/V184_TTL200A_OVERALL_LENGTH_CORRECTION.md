# V184 · TTL200-A 总长与 A14 接续管校正

日期：2026-11-17。

## 厂商图纸判读

依据 Thorlabs 工程图 TTN116903-E0W Rev B（11 May 2018）：
- 中央圆柱壳体长度：28.0 mm。
- 两端 SM2 外螺纹肩长度：各 3.2 mm。
- 完整轴向机械包络：28.0 + 3.2 + 3.2 = 34.4 mm。
- 中央壳体外径：Ø55.9 mm。
- 图纸两端标注孔径：Ø31.0 mm、Ø25.1 mm。
- 图纸注明仅供参考，不可直接用于制造。

图纸： https://www.oxxius.ru/upload/iblock/439/nnqcz1typ0xi4j8o1473uwc5izf6lyzm/TTN116903_E0W.pdf

经销商产品资料页也将 28.0 mm 标为 Housing Length，而非完整含两端肩部的总长。

## V184 修改

1. A08 WebGL / STEP：中央壳体从21.6mm改为28.0mm，保留两端3.2mm SM2肩，总长改为34.4mm。
2. A14：下端从Z=259.8mm上移至266.2mm，长度由63.2mm改为56.8mm；仍与A08上端肩保持3.2mm候选插入，并在Z=323mm处与A09相机代理底面接触。
3. A08光学参考工作距离的起算端更新至相机侧肩端面Z=269.4mm。
4. 更新浏览器、纯计算单元测试及STEP验证。新的A09代理机身距离窗口为53.6–98.6mm，相对148mm参考工作距离的最小差值为49.4mm。

## 不变的未知项

- TTL200-A内部真实玻璃、镜片曲率、实际安装方向和螺纹螺旋线未建模。
- A14仍是未识别型号的SM2接续管候选，不得据此采购。
- A09真实相机型号、法兰、传感器位置未知；148mm参考工作距离不能直接等同于传感器面距离。
- 图纸标注为信息用途，不可作为制造图。

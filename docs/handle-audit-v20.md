# V20 手柄方向纠错：照片108与109是相反观察面

本次针对用户指出的 V19 手柄朝向问题，重新人工检查原图108、109、95、97、100、110，并在网页上增设原图108/109对应的独立相机观察面，避免把相机透视方向误当成整机的固定坐标方向。

## 1. B 套 GCM-T25M：关键错误

- **108.jpg**：从 GCM-420302M 磁吸底座的 OFF/ON 铭牌正面看，下面水平 T25M 的银色测微手柄投影在画面**左侧**。
- **109.jpg**：从另一侧、能看清 **GCM-T25M** 和 **GCM-V25M** 名称标牌的一面观察，同一根 T25M 测微手柄投影在画面**右侧**。
- **不能因此认为 T25M 有左、右两根手柄，或者两图中原设备换了手柄方向。** 以前 V19 错把磁座铭牌、T25M 铭牌、V25M 铭牌绘制在同一 +Z 面，并由此把「左/右」简单硬编码进轴零件。

V20 采用一个清晰的**局部坐标安装方案**（仍属候选装配姿态）：T25M 的原生局部测微头沿 **+X**，带 T25M 标牌的前面是局部 +Z；将整个 T25M 以高度轴旋转约 **180°** 装配在磁座上，则其银色测微头在世界坐标中朝 **−X**，而 T25M 铭牌转到世界坐标 **−Z**。磁座 OFF/ON 铭牌仍朝世界 +Z。这样从 **108 磁座铭牌面看手柄位于画面左侧**，从 **109 T25M 铭牌面看手柄位于画面右侧**，同一根手柄在两张照片中得到一致解释。

**注意**：180° 是二维朝向匹配的候选，照片不是测量平台绕轴安装角度的计量依据；若真实组件还有翻面、不同导轨侧设计，必须按原厂 CAD/实物核实。

厂商 GCM-T25M 系列资料指出**测微头安装位置可以根据用途更换**。因此从两张照片的左右投影无法唯一推定整台 T25M 恰好旋转 180°，也可能存在不同侧安装、镜头斜视等情形。V20 使用的 180° 是可交互模型的**一致性候选**，并非对实物安装角度的确认。参考：https://www.directindustry.com/prod/daheng-new-epoch-technology-inc-cdhc/product-57930-2162027.html

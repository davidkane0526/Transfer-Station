# V204 · A14 镜筒纳入 A18 正面照片参考视图

日期：2026-11-18。

## V199 截图复核发现

对已生成的 Transfer-Station-A-V199-A18-Isolated-Photo-Reference-View.png 进行实物对照后，发现相机 A09 与 TTL200-A 管镜 A08 之间存在明显悬空间隙。原因不是 A14 的 CAD 实体缺失，而是正面参考视图的可见零件白名单只包含 A08、A09、A18、A19，遗漏了实际位于二者之间的 A14 候选接续镜筒。

A14 的设计包络为 56.8 mm，起点 Y=266.2 mm，终点 Y=323 mm。它与 A08 上端 SM2 肩部有 3.2 mm 候选套接，并在 Y=323 mm 与 A09 相机壳体底面相接。隐藏 A14 会让照片参考截图错误地显示相机悬空。

## V204 修改

1. 正面参考视图的可见零件集合增加 A14，不修改任何零件位置、尺寸或镜像关系。
2. 将 A14 套筒实体标记为 A14CameraBridgeSleeve，供几何探针单独读取。
3. 增加浏览器探针，分别测量 A08 上端肩部与 A14 的重叠量，以及 A14 顶端与 A09 相机底面的间距。
4. 浏览器回归要求参考视图同时显示 A08、A09、A14、A18、A19，并验证 3.2 mm 候选套接及 0 mm 相机底面间隙。
5. 保留原有正面左右约定：WebGL +Z 观察时屏幕右侧为 +X，A18 水平侧筒在照片右侧，线缆和刻度盘在照片左侧。

## 限制

A14 仍是未知型号的候选接续镜筒，56.8 mm 长度与 Ø56/Ø52.2 mm 外径/内径为当前装配候选值，不是已确认的原厂规格。A09 相机型号、传感器位置、螺纹和真实成像光路仍未确认。本次修正只恢复被参考视图遗漏的实体，不代表接口已获得实物认证。

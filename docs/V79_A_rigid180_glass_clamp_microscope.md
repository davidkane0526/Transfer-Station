# V79 · 平台 A 整体180°转向、玻片夹持与显微镜纠错

## 1. 本版纠错目标

本版直接针对用户2026-11-08截图指出的机械错误，不以“视觉近似”掩盖装配问题：

1. 载玻片侧必须整体转向样品，而不是只翻转末端A05。
2. 玻片是转移机构必需件，不能因为一张照片中透明轮廓不明显就从模型删除。
3. 两枚紧固件必须建立合理的夹持受力路径。V79把螺杆轴线改为平行玻片26mm短边，并通过活动压紧条施力。
4. 删除A15长期悬空的无来源中央圆柱控制件。
5. 显微镜未知部件不得用自造长圆筒和鹅颈支架冒充真实结构；能由厂家资料约束的部件按厂家规格重建，主机型号查不到时明确保留“待识别”。

## 2. 平台 A 膜侧刚体链

当前膜侧链定义为：

A17磁性底座 → A15 GCM-T25M双轴台 → A03 GCM-VC13M竖直台 → A04L下层摆角机构 → A04 GCM-G40M60L → A05折弯板 → A05C玻片夹 → A05G玻片/PDMS。

V79只保留一套局部左折A05几何。当前安装状态通过围绕A17/A15竖直中心线执行180°刚体旋转得到。A05、夹具、螺钉、玻片和上游位移/摆角机构使用同一旋转变换，避免旧版“底层转了、末端没转”或“只镜像A05”的不一致。

当前局部候选尺寸下，180°安装后的玻片X范围为10–86mm，PDMS中心X=78mm，与A07样品中心一致。该结果是模型几何配准，不是实物测量公差。

## 3. 玻片夹持结构

### 已删除的错误

- 两枚螺杆竖直穿过A05折弯脚。
- 为上述错误轴线虚构的两个A05竖直通孔。
- 仅旋转蝶形头外观、但不改变实际螺杆受力方向的处理。
- “无玻片实物装配”这一错误状态。

### V79结构

A05C现由下列几何候选组成：

- 下方支撑台：承托玻片；
- 固定侧挡：位于玻片一个长边侧；
- 活动压紧条：位于相对侧；
- 两个外侧螺杆座；
- 两枚A05CS侧向螺杆。

A05CS螺杆在WebGL中沿场景Z轴，在STEP中沿平面Y轴，这两个轴均对应玻片26mm短边方向。两枚螺杆沿玻片长度方向分布，候选中心距18mm。自动校验要求：

- 两根螺杆实际几何主轴与玻片短边平行；
- 螺杆与活动压紧条有实体啮合；
- 螺杆与玻片零体积穿透；
- A05折弯脚不再存在竖直夹紧孔；
- 支撑台、固定侧挡、活动压紧条与玻片为面接触而非穿模。

夹具SKU、螺纹、夹紧力和18mm孔距仍未由实物或厂家图确认，因此不可用于加工。

## 4. A15悬空手柄纠错

旧版A15正面长槽附近绘制了一个没有可靠照片/图纸机械连接依据的圆柱控制件A15FK，用户截图中表现为长期悬空的滚花圆筒。V79从WebGL和STEP删除A15FK。

A15两根真实平移测微组件改为连续链：支座 → 测杆 → 套环 → 微分筒。双轴台的硬尺寸继续由大恒GCM-T25M系列约束：65×65mm台面、双轴总高33mm、X/Y各±12.5mm。具体2L/2C后缀和安装孔仍需进一步确认。

## 5. 显微镜与照明

### A11 · Thorlabs MWWHL4

能确认厂家/型号的A11按Thorlabs资料约束：

- 散热壳外径Ø30.5mm；
- SM1接口；
- 原厂机械图MTN006388给出总长60.1mm、SM1(1.035-40)内螺纹深6mm，WebGL/STEP均按60.1mm总包络建模；
- 显示散热鳍片和独立电气线。

V75时期自造的“连接A18的鹅颈机械支架”没有实物依据，V79已从WebGL/STEP删除。SM1RC式滑环仍仅作为厂家支持的安装候选，不等于用户实物已采用。

### A18 · 主机调焦单元

照片191–193只足以支持以下拓扑：

- 紧凑黑色主机身；
- 上部光学接口；
- 下部物镜转换盘接口；
- 左右同轴粗/微调焦旋钮。

此前Ø32×160mm横向黑圆筒无厂家图纸或明确照片结构依据，V79已删除。当前92×88×70mm主机外廓仍为照片比例候选，厂家和型号保持“待识别”。Mitutoyo FS/VMU、Olympus/Evident BXFM等只用于外形检索对照，不做型号归属。Evident原厂BXFM-F图纸显示其为银色框架、Ø32H8支柱孔、30mm Z行程并具有明确M4/M8安装孔系；这些特征目前不足以与照片191–193中的黑色主机体一一对应，因此没有把A18强行改名为BXFM-F。

### A19 · 转换盘与物镜

只保留照片中可见的两支物镜，并将原简单圆柱细化为上筒体、中段、前端鼻部、色环和镜片面。左侧外倾22.5°仍是照片比例候选，中央工作物镜近竖直。局部可读的“PlanFL 10×/0.40”“MPLAN 5×/0.10”文字不足以唯一确定完整SKU，因此不将当前在售型号直接套用到实物。

## 6. 验收边界

V79解决的是方向、部件存在性、夹持受力方向和明显悬空/伪造几何问题，不等于完成整机制造级复原。以下仍待闭环：

- A05C真实厂商、型号、螺纹和夹紧行程；
- A17磁座厂家、顶底孔系和磁吸机构；
- A04L具体型号；
- A18主机厂家/型号、调焦行程及安装接口；
- A19两支物镜完整铭牌、转换盘孔位及真实工作距离；
- A11实际安装支架；
- A02/A06精确型号与原厂孔系；
- 实物光轴、工作距离和全行程碰撞验证。

在这些信息确认前，当前模型仍是受照片和已识别厂家尺寸约束的工程复原，不是加工图或采购验收图。

- **Thorlabs MWWHL4**：机械图MTN006388确认Ø30.5mm、60.1mm总长、SM1内螺纹深6mm。V79已同步修正WebGL、STEP、BOM和接口测试。
- **Evident/Olympus BXFM-F**：原厂图与规格可用于排除错误候选，但目前照片191–193没有足够铭牌/接口证据证明A18就是BXFM-F，因此继续保持“型号待识别”。

# V182 · A18 照片观察侧左右方向

日期：2026-11-17。

## 唯一观察基准

使用用户提供的高分辨率透明底显微镜抠图作为观察侧基准。相机位于抠图所示一侧（WebGL 局部 +Z），屏幕右侧定义为局部 +X。

| 实物可见特征 | 正确归属 | 当前几何约束 |
|---|---|---|
| 水平侧向光学筒 | 画面右侧 | 壳体 +X 面，90mm 外伸候选 |
| 柔性线缆 | 画面左侧 | 中央光轴 -X 侧 |
| 圆形刻度盘 | 壳体前面板左半侧 | 保留原位置并朝向 +Z |
| 中央光轴/物镜链 | 中心 | 不镜像、不平移 |
| 左右粗/微调焦轮 | 壳体两侧 | 保持成对结构，不随侧筒镜像 |

## V182 修正

- 将 WebGL 与 STEP 的水平侧筒、方形安装框、侧壁贯通孔和四枚安装紧固件从 -X 壳体面迁移到 +X 壳体面。
- 将柔性线缆从 +X 侧移到 -X 侧。
- 刻度盘不与侧筒一起镜像，仍位于壳体左半侧，并朝向照片观察侧。
- 添加基于真实网格世界坐标的浏览器探针，以及 STEP 的端口包络、贯通孔、线缆和刻度盘左右检查。
- 增加固定的照片观察侧截图视角，避免把相反观察侧下的屏幕左右误读为装配方向错误。

## 与平台 A 其他部件的边界

平台 A 玻片夹的 +X 夹持侧及已安装的刚性 180° 姿态是另一套坐标变换；不得把 A05 的世界坐标左右直接套用到 A18 局部照片坐标。A18 的此项修正不改变 A05、A17、A06、A10 或 A19。

所有新增尺寸均为照片拟合候选，未达到实测加工图精度。A18 的 OEM 身份、侧筒内部光学元件和接口螺纹仍未确认。


## V182 CI 验收脚本变量作用域修正

首次 STEP 回归在 A18 端口包络断言处失败，排查发现验证脚本前段 B35 网格扫描也使用了循环变量 cx，导致 A18 检查误读为 B35 的末次坐标。V182 几何本身的局部复算包络为 x=144..234mm、z=205..239mm，贯通孔与机身端面接触正确。修复后在 A18 验收段显式使用 a18_cx=78mm，避免跨设备坐标变量污染；不改变 V182 零件几何。

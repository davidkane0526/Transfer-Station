# V22 原厂 CAD 文件审计与装配坐标修正（2026-11-01）

## 严禁再混淆的三个概念

- **原厂文件已取得并解析**：原厂文件格式被确认，不代表项目公开发布了该文件，也不代表数字装配已经引用这份真实几何。
- **按原厂图纸重建的代理**：我们自己的 CadQuery/Three.js 实体，用厂商尺寸限制外廓，不能当成原厂 CAD。
- **制造级有效的接口连接**：必须明确上下安装面、螺纹/通孔类型、孔深、螺钉头类型与真实材料；只有外形匹配不代表可加工。

## Zolix NFP-1462C：官方来源已真正下载验证

- 原厂型号资料：[NFP-1462C](https://www.zolix-group.com/product/specification/179.html)。
- [原厂机械图 PDF](https://www.zolix-group.com/public/storage/upload/files/Motioncontrol3D/NFP-1462C.pdf)。
- [原厂 2D/3D CAD RAR](https://www.zolix-group.com/public/storage/upload/files/Motioncontrol3D/NFP-1462C.rar)。
- GHA 已成功从官方地址解包得到 **NFP-1462C.step（2,413,693 B）**、**NFP-1462C.x_b（654,054 B）**。RAR SHA256 `a74ccecf102a8da5e491ec58ab23f6b9a5e15a708f92071ddabb7aa85c2f8b6f`。
- 实际 STEP 是 **1个Compound、44个Shell、815个Face、0个封闭Solid**，几何有效但不可直接作为封闭实体布尔/加工。原厂几何包络 **27.6 × 77.5 × 167.5 mm**（官方文件原始坐标），在CI中已成功**本地**转成 STL，原生文件和网格均未上传公共仓库。
- 原厂产品标称台面 **65×65 mm**，台体厚度 **23±0.1 mm**，X轴行程 **25mm**，总长（测微头伸出后）图纸标为 **155.5–180.5mm**。由含锁止件的 CAD bbox X27.6 与标称厚23的差异不能断言台体真实厚度变化。
- 原厂图纸分开标注 **4×Ø6.5通孔，Ø11沉孔，50×50mm孔距**；以及 **9×M6，25mm网格**、**4×M3，32mm网格**。原CAD上各视图、安装面与移动件要配合实物进一步定位，**不应把 Ø6.5/Ø11通孔误作M6内螺纹孔**。
- 原厂图画测微头朝图纸左侧，而用户原图 `110.jpg` 看到实物朝右；V22用**整个NFP绕高度轴180°的安装方向候选**匹配右向，而不是把原厂零件的局部测微头硬改到另一边。

### 为什么不能直接把 STEP 替换到公开网页

1. 该 STEP 由非封闭曲面/壳体构成，旧脚本要求至少1个封闭 Solid 因而错误地拒绝它，现已修复为只要求有效可三角化 Face。
2. 原生 STEP 轴顺序为高(27.6)/宽(77.5)/长(167.5)，不是网页的 **X横向/Y竖直/Z前后**。
3. 模型最长方向包含测微头，不能按整个模型包络居中就认为 65×65 台体中心与旋转台对齐。
4. 官方 CAD 没有授予本项目公开再分发的明确许可时，不把原厂 STEP / 派生 STL 直接提交到公开仓库。
5. 即使显示外形准确，还必须实测孔面朝向、孔深、有效螺纹，以及与加热块四角沉入式螺钉的真实连接。

### 本地取得真实外形的操作

从[官方页面](https://www.zolix-group.com/product/specification/179.html)的 **2D/3D CAD File** 下载 `NFP-1462C.rar`，用7-Zip解压。其中含 `NFP-1462C.step`。本地机器安装 CadQuery 后运行：

```bash
pip install cadquery
python cad/convert_vendor_step_to_stl.py NFP-1462C.step vendor-local/NFP-1462C.stl --preset nfp1462c
python -m http.server 8765
```

在网页中选中 **B09 NFP-1462C**，在“导入原厂三维CAD”内选择“**NFP-1462C 原厂 STEP 轴向预设**”，导入转换后的 STL。

脚本将原生轴循环映射 `(X_oem,Y_oem,Z_oem) -> (Y_web,Z_web,X_web)`，也就是 OEM X→Web Y、Y→Web Z、Z→Web X。它是120°真实旋转，不使用镜像；可以检查转换后尺寸约为 **167.5 × 27.6 × 77.5 mm**。

网页通过把最长轴包络的一端按65mm台体近似锚定，提供X/Y/Z三轴偏移和Y轴局部旋转微调。**初始位置仍然是候选！** 未经实际安装孔对准和螺纹验证，不标记为“原厂接口已闭合”。

此外，使用：

```bash
python cad/audit_vendor_archive.py --archive NFP-1462C.rar --report ./report.json
```

可重复获取**只有文件清单、哈希及BRep结构**的报告。GitHub Actions 工作流 `audit-vendor-cad.yml` 已自动验证下载/解包/转换，但只向用户交付元数据。

## 尚未解决的硬问题

**四枚自制热台紧固件：** 用户确认四枚靠近四角、顶部齐平、无过渡板。从 OEM NFP PDF 的孔系可以找到50mm方形通孔、25mm网格M6、32mm网格M3三种结构，但尚不知热台四枚螺钉到底使用哪个面上的哪一组有效螺纹，也不知道它们在NFP中有效啮合深度。此前生成器的 M6×25 与10mm盲孔仅用于候选几何，绝不能据此采购/加工。

**原厂STEP并非闭合Solid**：虽然经过转换能在网页中真实显示外形，它仍不能用于可靠的干涉布尔运算。应与用户核实可装配尺寸，再根据原厂曲面重建制造级封闭实体，或向厂商索要Solid版CAD。

**原始照片是实物证据**：原图 `110.jpg` 显示NFP和旋转台、上方隔热层与金属加热台的相对关系，以及右伸测微头。只用厂家PDF左向截图判断实际安装方向会再次犯错。

另识别到 **97 个竖直轴向圆柱曲面**、**100 个与开放 Shell 圆柱面关联的圆边**、**92 个多级同轴圆径候选圆边**。Ø6、Ø6.5、Ø11 mm 各分组使用直径容差筛选，因此统计边缘数量可能与严格单一类别标签略有差异。以上“2”可能来自不同高度或重复表面，**不代表两组独立的四孔机械结构**。

## 分层证据处理

1. `cad/extract_oem_features.py` 只根据厂商 BREP 提取圆心、半径、法向及其所在 Web 坐标系，私有文件中保留逐圆详细坐标。
2. `cad/classify_oem_mounting.py` 关联同轴圆柱面、不同高度的圆环与多级直径。**封闭 Solid** 可使用正常的内向/外向面方向辅助区分孔壁与凸出轴壁。**NFP 只有开放 Shell**，即使同轴圈和圆柱壁完整，也只标记 `surface_shell_unresolved`，不推定内螺纹。
3. 按候选 Ø6.5、Ø11、Ø6 mm **分别**统计 25/32/50 mm 几何排列，避免把 9 孔格阵列的外侧四角误作独立固定孔系。
4. `tests` 中所有自造圆孔、沉孔和轴心仅验证算法，并不是原厂实测数据。详细 OEM 几何由持有原厂文件的人在本地检查，不公开发布。

## 装配验收仍需补充

- 固定台与移动台的区分、真实安装面方向、对应旋转台和上方隔热块的实际孔心；
- 四枚顶部齐平螺钉究竟使用 **9-M6 还是 4-M3 或其他**孔组；目前不可以自作决定；
- 螺钉头与沉孔的实际尺寸、螺纹有效深度、夹紧厚度、热应力及安全性；
- 原厂 NFP 完整移动行程需要分离运动件与固定件，未分解的整件 STL 不可用于运动干涉验证。

当前检测只提高**几何分类可解释性和工程待核查效率**。任何软件 PASS 不代表实际可直接生产、采购或者安装。

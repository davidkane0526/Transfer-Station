# V23 真实机械接口验收账本（2026-11-02）

## 与几何检查的区别

本项目已建立以原厂图纸、用户实物照片和用户确认结构为依据的装配数字样机，但工程验收必须区分：**外形网格可显示**、**假设几何可装配**和**真实接口可直接加工/采购**。当前 B08–B09、B09–B14、B02–B04、A15–A04、A06–A07 等接口均未满足第三项要求。详见 `src/interface-evidence.js`，网页点击相关零件时显示对应缺失信息，BOM CSV 亦包含 `interfaceReview` 与 `interfaceGaps` 两列。

## 最高优先级：B09 与 B10/B11/B14

- **已知事实（U）：**顶面四枚靠近角部的螺钉头齐平；中间没有额外金属过渡板；金属块底部有陶瓷加热器和隔热层。
- **厂家记录（D）：**NFP-1462C 的孔位图分别标出固定面 4×Ø6.5、Ø11 沉孔和可运动面 9×M6（25 mm 网格）、4×M3（32 mm 网格），不能以外形相似将 Ø6.5 沉孔误当作 M6 螺纹孔。
- **未知：**四枚螺钉实际对应的孔组，真实四孔中心坐标，固定/移动面的识别、穿过隔热层的有效夹紧尺寸、螺纹啮合深度与螺钉头沉孔尺寸。
- **仅为候选（I/C）：**50×50 mm 角部孔距、M6×25 螺钉、10 mm 盲孔和模型计算出的 0.5 mm 轴向净隙。这些数值不是实测，不能凭校验测试升级为 D 或 U。

需要采用统一的局部坐标：从加热块顶面俯视，原点设在唯一中心吸附孔，X 朝真实照片右方，Z 朝观察者前方，Y 向上。记录四枚螺钉中心相对于原点的 (X,Z)、沉孔口径/深度、上块与隔热板厚度，并以 OEM NFP 的真实安装面定位相应螺纹孔。若未测量，应保留 UNKNOWN，不用50mm方格自行补全。

验收前应逐项确认：螺钉能够沿真实安装路径进入正确攻丝孔、最大公差/热膨胀条件下不会触底、有效啮合长度满足厂商要求、不与滑台运动件和真空/加热结构冲突。200°C 热区还必须独立审查材料、绝缘、热接触、热应力及固定件受热后的预紧力。工程样机的相交测试不能替代这些审查。

## 第二优先级：B08 与 B09 固定座

照片110/111可确定上下层级，但不能从照片精确推断 NFP 固定面与旋转台的孔轴一致。需要原厂 CAD 的真实固定面及原厂机械图同向配准，确认相对角度、孔坐标、沉头螺钉头高度、装配工具空间，以及旋转及平移全行程的实体碰撞。当前网页版原厂 STL 是整个未拆分壳体的静态网格，不能用于验证固定座和滑台相对运动。

## 双轴滑台和其他未闭合接口

- B03 与 A15：厂家组合图约束 65×65×33 mm、两根正交测微头，但具体2L/2C后缀及所用孔/螺钉尚未从实物确认。
- A02：照片100只证明单一可见手柄与独立位置，不能据此排除被遮挡的第二轴，故单/双轴状态待核。
- B11/B12/B13/B15：已确认后侧真空管和两根加热线的方向，电功率、热电偶种类、接头螺纹和气密性仍待测。

## 自动检查和验收门槛

测试 `tests/interface-evidence.mjs` 检查每条账本指向存在的零件、所有关键接口保留 pending 状态、相关 BOM 记录包含所缺测量项目。浏览器测试检查 B09 选中界面的“物理装配接口验收”提示。CI 测试通过的含义只限于软件记录与候选结构逻辑自洽，不代表物理尺寸验收、厂家 Solid 模型、实物干涉和热/电安全通过。

## 厂家几何

Daheng GCM-901604M原厂组合机械图给出4×Ø7 / Ø11沉孔、50×50 mm，并注明M6紧固。该图证明Daheng标准组合存在这种四点M6安装模式，但不能证明用户实机A15底面一定采用同一模式。

Oeabt当前MBS-65产品页给出MBS-65B为M4×4、M6×9，MBS-65C为M4×12、M6×1，且周边孔采用25×25 mm阵列。MBS-65B的3×3 M6网格因此具有50×50 mm四角M6子集；MBS-65C没有四点M6能力。

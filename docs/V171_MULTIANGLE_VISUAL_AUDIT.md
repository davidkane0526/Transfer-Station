# V171 多角度视觉审查与错误闭环

## 图像来源 / 不确定性

- 用户本次截图明确指出：A/B热台的蓝色方形面不应被视为硬件；平台A显微镜与光源仍明显不符合实机。
- 现有仓库照片191–196只有127×170px预览，不具备真实A10/A18固定孔系或LED独立安装方式的制造级辨识能力。照片147为平台B。图像识别仅用于判断大方向、占位与视觉错误。
- MWWHL4厂商工程图MTN006388显示Ø30.5×60.1mm、前端SM1内螺纹深约6mm；与实际装配灯头SKU一致性仍需高分辨率铭牌确认。

## 完成的具体修正

1. 删除两个加热台在默认状态下的蓝色片层；A07W不再进入安装版总STEP，但仍保留独立可选演示附件，平台B原本仅存在于WebGL场景。
2. 重建A11光源面向显微镜一侧的SM1口部，将散热片远离SL1RC滑环，尾线与A22连续。
3. 把A20短悬空数据线延伸至后侧服务边界外。全路径仅为可视化候选，不认定真实插头、固定夹或通信标准。

## 机械真实性限制

- A10/A18是否同一OEM壳体、A21独立灯柱是否真实安装、LED确切光路和相机真实传感器位置均未由照片确认。不得把外观改良写成实物结构已验收。
- A07W高度位置仅用于PDMS下落接触算例；如果关闭样品演示，热台应呈裸露金属台面、吸气孔和四角紧固件。

## A11 LED 出光端的进一步视觉修复

原厂 MWWHL4 模块实拍中的发光端有清晰可见的黑色电路板和黄色LED发光区，旧模型则为没有细节的米色圆盘，容易误判为封闭光源。按原厂 MTN006388 Rev D 工程剖面和 Thorlabs 展示图，将默认出光端改为黑色PCB代理、暖白色小发光区及少量可见触点。PCB图案和发光芯片封装未获得原生CAD，所有内部尺寸均为视觉候选；原厂Ø30.5×60.1mm外廓、前端6mm SM1内螺纹口、SM1RC夹环位置及缆线连接不变。

# V40 · B40真空软管运动包络与电气线束间距审计

日期：2026-11-04

## 1. 修改原因

V39已将B40从B36电控箱左侧绕至机箱后侧，再绕右侧接入VN-50候选吸入口。但复核发现，V39虽然检查了B16、B19和B36的实体干涉，却没有将B40与B37加热双线、B38测温线进行距离验收；其样品运动测试也只覆盖若干边界姿态，不能代表完整的平移/旋转组合范围。

V40因此同时修正布线高度和验证范围，不改变用户要求的“绕过温控器背后、沿机箱后方绕行”总体路线。

## 2. V40管路路线

坐标约定：

- 网页 Three.js：X为左右、Y为竖直、Z为前后。
- STEP/CadQuery：X为左右、Y为前后、Z为竖直。
- 两套坐标通过 `(X, CAD-Z, CAD-Y) ↔ (X, WebGL-Y, WebGL-Z)` 对应。

B40从B15T移动端名义点(94, 90.5, −79)出发，先从B16立柱右侧通过，再从B36左侧绕行。机箱后侧的长直段降低至**CAD竖直Z=70mm / WebGL竖直Y=70mm**，从B19温控器背侧对应的机箱后方通过，随后绕过B36右侧并接近VN-50候选吸入口(425, 68, 180)。

## 3. B37/B38线束间距

V40的距离审计复用了网页端 `refreshHeatingControlHarness()` 的动态路径定义：

- B37A：加热双线中的第一根，候选半径1.1mm。
- B37B：加热双线中的第二根，候选半径1.1mm。
- B38：测温反馈线，候选半径0.72mm。
- B40：真空软管外半径3.5mm。

对每一条线束，计算B40与其中心线各线段的最小三维距离，再减去两者的外半径，得到表面间距。验收阈值为**大于2.0mm**。该检查用于避免模型中管线实体相交或过近，不代表电气绝缘、热安全或实际固定方式已经验收。

CAD验证另使用STEP实体距离检查B40与B37、B37A、B38之间的最小距离，阈值同为2.0mm。

## 4. 样品运动包络

样品运动范围按现有机构候选行程设置：

- X平移：−12.5至+12.5mm。
- 绕竖直轴旋转：−30°至+30°。
- 平移采样步长：1mm，共26个采样值。
- 旋转采样步长：1°，共61个采样值。
- 总计：**1586个组合姿态**。

每个姿态都重新计算B40移动端、软管路径、B16立柱间隙、B19/B36间隙及B37/B38线束表面间距。任一姿态低于阈值，审计函数即报错，浏览器回归测试不能通过。

这是确定性离散网格采样，不是对相邻采样点之间所有连续姿态的数学证明。后续若获得真实软管最小弯曲半径和固定点位置，还需进行更精细的柔性管路扫掠体分析。

## 5. 自动检查

- `src/b-vacuum-routing.js`：动态B40路径、B37/B38对应线束路径、线段间距和1586姿态运动网格。
- `tests/b-vacuum-routing.mjs`：Node单元测试。
- `tests/model-b-visible-smoke.mjs`：真实浏览器场景探针及后侧视角截图。
- `cad/build_assemblies.py`：STEP中B40路径与网页端采用同一组名义节点。
- `cad/validate_interfaces.py`：B40与B36、B19、B16、泵体及B37/B37A/B38的实体间距检查。

## 6. 尚未实测的项目

1. B40实际内外径、材料、耐温等级、真空等级和最小弯曲半径。
2. B15接头的真实螺纹、倒钩/快插形式及密封结构。
3. VN-50实际吸入口在泵体上的位置、方向和接头规格。
4. 软管固定夹位置、泵端隔振和样品运动时的动态弯曲余量。
5. B37/B38真实端子、导线规格和电气安全要求。

因此V40只表示候选几何的路径与间距检查通过，不应直接作为采购加工图或设备安全验收文件。

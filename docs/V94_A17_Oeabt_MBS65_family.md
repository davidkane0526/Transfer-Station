# V94 · A17 Oeabt MBS-65B/C 厂商家族审计

## 1. 新证据

重新检查仓库中的照片194低清预览，可以稳定辨认A15下方A17磁座的两个外观特征：

1. 正面存在一块浅色长方形铭牌区域；
2. 铭牌左侧有独立银色磁力ON/OFF开关。

这两项此前只被粗略抽象成“65 mm黑色方块 + 侧开关”，没有进入厂商筛选的核心证据。

## 2. Oeabt MBS-65B/C

Oeabt 2025官方产品册及产品图显示：

- MBS-65B / MBS-65C外形均为65.2×65.2×20 mm；
- 保持力158 N（约16 kgf）；
- 正面有横向OFF…Oeabt MBS-65x…ON彩色铭牌；
- 左侧有银色磁力开关；
- B/C外形与开关拓扑相同，差异主要在顶面螺孔阵列。

顶面孔阵：
- MBS-65B：9-M6并配4-M4；
- MBS-65C：1-M6 + 12-M4。

照片194中A17顶面被上方A15完全遮挡，因此现有证据不能区分B或C。

## 3. 为什么替代PTDB65成为主候选

CORZC PTDB65同样是65×65×20 mm薄型磁座，也有银色ON/OFF开关，因此仍然是合理的次候选。但其正面标记/外观与照片194的长方形浅色铭牌匹配度弱于Oeabt MBS-65B/C。

LBTEK MB65也属于相同尺寸和左开关家族，但其正面文字布局同样不如Oeabt候选接近。

因此V94的排序为：

1. Oeabt MBS-65B/C：主候选族；
2. CORZC PTDB65：次候选；
3. LBTEK MB65：次候选。

## 4. 实体改动

WebGL与STEP均增加独立的A17正面铭牌板。铭牌文字只写OFF / OEM ? / ON，不写Oeabt或具体型号，因为128×170公开预览无法读取实物铭牌文字。

顶面继续保持0个建模孔位。任何MBS-65B/C候选孔阵都只存在于元数据/验证报告中，不进入实体。

## 5. 自动约束

- A17正面必须存在且仅存在一个铭牌实体；
- 铭牌必须贴合A17正面而不能穿入本体；
- 铭牌必须位于左侧银色开关右侧；
- A17模型顶面候选孔数量保持0；
- 主候选族必须为Oeabt MBS-65B/C；
- exact variant仍为false；
- CORZC PTDB65与LBTEK MB65必须保留为次候选，防止过早锁定品牌。

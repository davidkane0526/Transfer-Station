# V32 模型B双安装板与样品高度审计（2026-11-04）

## 实物证据

照片145下方可直接看到 **THORLABS** 字样、孔阵列和黑色安装板外缘，且 GCM-11 圆形旋转台下表面接触该黑色板；照片150从俯视角表明黑色板占据样品侧区域，左侧磁座机构下方另有银色公共光学台面，两者存在明确边界。**因此此前将整个B系统视为一块统一板、使B08旋转台直接贴着银色台面的建模方式与实物不符。**

## 验证标准

1. `cad/validate_interfaces.py` 要求B35底面接B01顶面、上表面接B08旋转台底面；不得与显微镜独立立柱底座、左侧磁座或共用板相交。
2. B35上方的孔为 **2 mm深外观盲孔候选**，背面必须有金属，不能用未经厂家确认的通孔冒充M6固定孔。
3. B09上表面随B35整体抬升到88.2mm，B11金属吸附台上表面为110.2mm，B14螺钉头顶部为109.7mm，相关孔深及沉孔检查同时平移。
4. 网页浏览器验证B35出现在场景、证据树和BOM中，并在样品侧放大图中保留独立黑色安装板。
5. 所有尺寸仍属于当前相机空间坐标系下的假设。B35本体外形、孔距、真实厂家零件号和公共板固定方式均**未实测，不允许作为制造图纸**。

实物对应：用户照片145和150；未对黑色板编造厂商型号或价格。

# V134 · 平台 A 控制线路动态避碰与照明支架夹紧

2026-11-11，承接已保存的用户优先级 04 要求。此版先在隔离的容器中进行 Node.js 运动测试和 CadQuery 夹紧结构实体测试，再将修改集中提交 GitHub。

## 根因与修复
1. **加热/测温线穿模**：V133 的 A23/A24 线束从 A07 后侧接出，但后续引导点固定在全局坐标；当 A06 旋转至约 90°–180°，原本的“后方”成为舞台前方，第一段可穿过 65 mm 级加热台。现前两个线束引导点在 A07 台体局部坐标下随 X 平移与旋转，同时通过高空服务线道绕开独立 A12 LED 驱动器。
2. **错误的运动方向审计**：世界 `Z<0` 并不等于旋转后热台的后侧。已改为与 A07 局部后侧位置匹配的三点校验。
3. **A21 零面积搭接**：横杆先前顶端仅触及末端连接块下缘，几何交集体积为零。V134 抬高横杆 4 mm，CadQuery 验证横杆与连接块具有正体积接合。
4. **缺少锁紧机制**：在固定立柱的活动套环和 LED 安装环中分别加入径向锁紧螺钉，STEP 中建立真实径向通孔，螺钉末端名义接触立柱与灯体而不是直接穿模。WebGL 锁紧零件仅为装配显示代理，不作为螺纹加工图。

## 本地验证（不是 GitHub Actions 结果）
- `node tests/a-control-interfaces.mjs`：单元测试通过，正负 180° 旋转后局部背面出线位置判定保持正确。
- `node tests/a-control-clearance.mjs`：365 组样品姿态（5个 X 位置 × 73 个旋转角），折线近似下最小加热台净距 1.716 mm、外部 LEDD1B 机壳净距 20.330 mm。
- `node tests/a-control-spline-clearance.mjs`：同范围 centripetal Catmull-Rom 曲线采样，最小加热台净距 1.728 mm，A12 驱动器机壳净距 23.589 mm。A07 穿线起始 3mm 属接头区域，不纳入非端口碰撞统计。
- `python tests/test_a21_fixture.py`：独立 CadQuery 检查 0、9、18mm 三组光学停车假设姿态，底脚四孔、立柱、横杆、连接块、滑环、锁紧螺钉及径向穿孔均有效，未复现零面积搭接。
- 最小净距以目前候选外壳和线径为边界，不代表完整机器运动、实际线束弯曲半径及电气功能已经认证。

A21 独立支撑柱是否真实存在、MWWHL4 夹环具体 SKU、A07 热源/温度探头类型、A13 真实负载端与电源、独立温控器及真实电气接线均尚未确定。模型与原理图不能用于直接通电。

# V23 · 原厂 CAD 网格导入的可逆性与运动真实性审计（2026-11-02）

## 本版解决的问题

截至 V22，平台 B 的 NFP-1462C 可在本地导入原厂 STEP 转换出的 STL，但此前的可视化行为存在两个不应忽略的失真风险。

1. **测量混合了隐藏的代理几何与导入网格。** Three.js 的组级包络计算即使代理 Mesh 已隐藏，也可能计入其边界。V23 改为只汇总当前可见 Mesh 的世界坐标包络。显示数值是渲染网格的包络，不是孔距检验或三坐标测量。
2. **整件原厂网格不等于可运动总成。** NFP 官方 STEP 含多个壳体，但本地转换为单个 STL 后没有明确分离固定座与运动滑台。V22 的样品滑块仍会驱动代理运动块和上方热台，却不会正确驱动原厂网格中的对应面。V23 在 B09 存在导入网格时将样品平移归零并禁用，明确标注静态显示限制。旋转展示仍是用户照片支持的安装朝向候选，并不验证接口。

本版另外加入“恢复原代理几何”按钮。恢复时移除导入网格、释放关联渲染资源、清除旧拾取对象，并恢复代理几何及候选的样品平移仿真。重选同一文件再次导入也受支持。导入期间如果用户切换了选中零件或平台，不会把旧网格错误挂载到新场景。

## 使用及验证

1. 在平台 B 选中 **B09 · NFP-1462C**，将本地厂商文件按 `cad/convert_vendor_step_to_stl.py --preset nfp1462c` 转换并导入。该文件仅供用户本地使用，不提交公开仓库。
2. 导入后确认外廓显示接近 **167.5 × 27.6 × 77.5 mm**。这些值来自原厂完整曲面网格包络，其中包括长测微头，并非 65×65 mm 台面尺寸。由于整体旋转和当前安装配准，显示的世界包络可能随局部偏航变化。
3. 应看到“整件静态网格”警告及已禁用的样品平移；显示配准 X/Y/Z 偏移及 Y 轴旋转属于人工候选，不代表实际机械安装。
4. 点击“恢复原代理几何”后，应能再次调节样品平移。隐藏孔位开关也不应重新显示被替换代理的孔位导引。
5. 浏览器回归测试 `tests/smoke.mjs` 用**人工合成的尺寸夹具**验证导入、可见包络、静态运动锁、孔位切换和恢复操作。它与 `tests/vendor-nfp-preview.mjs` 在临时构建机使用的官方原厂网格**严格区分**，不能将测试夹具称作原厂 CAD。

## 仍未闭合的物理装配证据

- **四枚顶部齐平螺钉：**确认数量与大致位置，但尚不知道对应 NFP 移动面上的哪组实际攻丝孔；原厂 **4×Ø6.5/Ø11 沉孔是固定座安装通孔，不可作为 M6 内螺纹**。此前 M6×25、10 mm 候选盲孔及 0.5 mm 轴向净隙只用于模型自洽性验证，不能作为采购或加工依据。
- **原厂安装基准：**需要从原始 B 套实物及厂家孔面图确定固定面与移动面、孔中心世界坐标、是否需要安装时 180° 转向、行程零点和运动方向。完整 STL 的包络中心不能代表台面中心。
- **运动学验证：**要在原厂曲面数据中识别固定壳体与可移动壳体并各自建立正确的关节约束，才能恢复“原厂网格随样品平移”。
- **热台与隔热板：**应核查真空吸附头四角孔位、沉头直径、实际板厚、螺钉头长度、NFP 螺纹有效深度及热膨胀条件；200°C 热区的电气绝缘、材料与热应力需要单独工程校验。
- **其他关键件：**大恒 T25M2L / T25M2C、V25M、旋转台和显微镜仍使用图纸与照片约束的代理，需要厂家原生 STEP 或完整孔位图。

## 证据等级与发布限制

**D**：厂商图中明确的尺寸或官方模型的外形；**P**：照片直接可见；**U**：用户确认的关系；**I**：根据已知孔系推导；**C**：无实测的候选。无法确认的尺寸不得从程序里“测试通过”转写为 D。公开 GitHub Actions 只发布截图/结构统计，不复制原厂 STEP 或派生 STL；以厂商实际许可为准。

## V23 增补：用真实对应安装特征点替代外形包络估算（2026-11-02）

在平台 B 选中 B09，导入私有转换的 NFP STL 后，网页新提供“对应安装特征点配准”。该功能根据至少两对**真实可一一识别的特征点**在 X/Z 平面计算刚性姿态，不允许缩放尺寸。其目的在于减少测微头伸长对整体包络中心造成的偏差，并不自动识别孔心。

1. 从 NFP 原厂 STEP 转换后的 **STL 实际轴向**读取孔心或经过可靠测量的基准特征点 `X,Z`；若导入单位为 m，输入仍应换算为 mm。
2. 以 **B09 装配组的局部 X/Z** 表示对应目标点，不要使用绝对的面包板世界坐标。模型默认安装朝向存在 Y 轴 180° 候选旋转，其世界 X/Z 与局部值可不同。
3. 分别填写两对以上“源 STL 坐标”与“目标装配局部坐标”。优先使用三个非共线、可从厂商资料唯一识别的点。当前没有自动生成真实孔位目标的功能，也不应把 50mm/25mm 网格的猜测作为实测点。
4. 点击“按实测对应点配准”。软件求解单一 Y 轴偏航角和 X/Z 平移，不会改变 CAD 的单位尺度；配对点间的几何距离若冲突，会拒绝，误差门限 0.25 mm **只用于拦截错误的对应关系，不是制造精度、螺纹同轴度或设备公差**。
5. Y 高度继续采用原有粗略基准加人工 Y 偏移。旋转台到 NFP 固定面、NFP 移动面到隔热台的真实安装面法向及螺纹深度仍需实物证据。两点拟合无法发现反射或安装面不一致，第三个点能增加一致性检验。
6. 再次点击原有“应用局部配准修正”会切回手动包络偏移并取消特征点求解状态；“恢复原代理几何”移除导入网格和记录。

对应数值仅存在于当前浏览器页面，不会作为公开仓库制造数据保存。测试 `tests/cad-registration.mjs` 和 `tests/smoke.mjs` 使用**合成坐标/网格**，绝不可将测试坐标视为 NFP 原厂安装坐标。真实厂商文件仍按此前所述保持私有。

## V23 增补：直接从原厂 STEP 提取候选圆心（2026-11-02）

此前的对应点配准要求人工从原厂模型读取 X/Z。本项目现在提供 `cad/extract_oem_features.py`，读取 STEP/IGES 中的圆形 BREP 边缘，提取其**原始圆心、半径、法向量、圆弧覆盖角度及其所在平面方向**，并按与 STL 转换器相同的 NFP 坐标旋转 `(OEM X,Y,Z)→(Web Z,X,Y)` 导出局部候选特征。注意原厂 STEP 包含多个未封闭壳体，不能通过这些二维圆边判定孔是否贯通、已攻丝或允许承载。

在本地使用（无需上传厂家 CAD）：

```bash
python cad/extract_oem_features.py ./NFP-1462C.step --preset nfp1462c --output ./private/NFP-1462C-feature-candidates.json
```

私有 JSON 中 `candidate_features[].center_mm` 为转换后、尚未包络居中的坐标 `[X,Y,Z]`。将真实安装面上经过原厂图与零件实体共同确认的圆心 **X,Z** 输入网页源点栏，将对应的 B09 装配局部坐标输入目标点栏。优先取三组不同且明确归属于同一个安装面的特征；不要仅依据半径 3.25 mm 或 5.5 mm 就把圆边判定为安装通孔或攻丝孔。若真实坐标仍不明确，继续将其标注为待验证。

`horizontal_plane_candidate` 只表示圆边法向近似平行 Web Y，`diameter_hint` 仅表示几何圆直径接近 6.5/11/6/3 mm。即使 `full_circle_candidate` 为 true，也不能由此认定机械安装接口已验收。函数 `mounting_hole_verified` 和 `thread_verified` 默认恒为 false。软件分组精度 0.02 mm 仅用于重复曲线合并，不能解释为厂家尺寸公差。

**保密边界：**生成的详细原厂候选圆心 JSON 只保留在个人电脑，不提交公共仓库，也不作为公开 Actions artifact。远程厂家 CAD 审计仅将候选数量、直径类别统计和无验收声明加入公共元信息，继续只上传非 CAD 的渲染截图与汇总统计。测试 `cad/test_extract_oem_features.py` 使用自行生成的合成孔位 BREP。

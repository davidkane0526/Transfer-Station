日期：2026-11-05

## 本轮依据

用户提供的带尺实物照片147（2026-11-05再次展示）与此前NFP-1462C照片、原厂图纸。该照片可直接看到：

- 最下方是黑色Thorlabs局部安装板B35。
- 其上为GCM-1107M圆形旋转台B08。用户明确纠正：该旋转台没有外伸操作手柄。
- B08上方还有一整级银色线性平移台，其微分头朝操作者前方，记为B41。
- B41上方另有一整级线性平移台，其微分头朝右，已识别为Zolix NFP-1462C，记为B09。
- 两根线性测微头分别属于两级不同的滑台，不得合并成一个零件，也不得把任何一根归到旋转台。

## 当前装配顺序

B35 → B08（旋转，无外伸手柄）→ B41（前向单轴，型号待核）→ B09（右向X单轴NFP-1462C）→ B10隔热层 → B11真空加热块及B12/B13/B14/B15子件。

## 几何与尺寸边界

| 项目 | 当前模型处理 | 证据等级 |
|---|---|---|
| B09外形 | 65×65×23 mm，按NFP-1462C原厂资料 | OEM |
| B09轴向 | 右向X，独立测微头 | 实物照片+OEM单轴规格 |
| B41外形 | 约65×65×23 mm的场景拟合 | 照片147尺标比例候选 |
| B41轴向 | 实物Y向前后平移（Web场景坐标+Z），与B09的X轴正交 | 实物照片 |
| B41测微头总长 | 约135 mm场景拟合（65 mm台体+约70 mm前向突出量） | 照片147比例估算，非原厂尺寸 |
| B41型号 | 不填入NFP-1462C，不伪造具体SKU | 未确认 |
| B08操作手柄 | 删除外伸手柄，保留旋转刻度及安装孔 | 用户明确纠正 |
| 上层加热组件 | 因增加B41，整体上移23 mm；B10/B11/B12/B13/B14/B15同步上移 | 装配层级推导 |

B41的确切产品型号、固定底座孔距、移动面孔系、行程及总高仍需清晰铭牌或原厂图纸确认。65×65×23 mm仅是当前模型的场景拟合，不是已确认的采购规格。

## 新增轴引起的高度配准

B41使B08以上的样品/加热组件整体上移23mm。为避免玻片、PDMS与加热块发生实体穿透，B06夹持组件、B24 PHUC-1、B25/B28横杆及玻片整体同步上移23mm。玻片至加热台的初始间隙仍保持约14.8mm，PDMS接触行程约13mm。B27竖直接杆在当前STEP中采用Ø12×112mm场景拟合长度；该长度不是已确认的Zolix标准SKU，实物长度及是否含延长接头仍需核实。

## 运动关系

- B09独立驱动上层X向滑块。
- B41独立驱动下层Z向滑块，并携带B09及其上方全部加热/真空组件。
- B08只提供旋转自由度。
- 旋转时，B41和B09两条平移轴随B08整体旋转，保持相互正交。
- 下降碰撞审计同时考虑两级平移、旋转角度及载玻片侧深度位置。

## 验收要求

1. 场景中B08没有外伸手柄。
2. B41和B09各自有一个可见且独立的测微头。
3. B41测微头朝前（Web坐标+Z），B09测微头朝右（Web坐标+X）。
4. B41移动时，B09、隔热层、加热块、陶瓷加热器、温度探头、真空接头和样品表面共同移动；B09自身X移动不能带动B41固定底座。
5. 两级台各自包含固定底座、活动滑块、台面及独立紧固件。
6. STEP/CAD模型中的B08、B41、B09安装面连续接触，不得穿透或悬空。
7. B41的未知孔系不得标记为已验证，也不得据此生成加工图。

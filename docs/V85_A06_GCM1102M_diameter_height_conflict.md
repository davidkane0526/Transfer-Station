# V85 · 平台 A 样品旋转台 A06：GCM-1102M 直径吻合与高度冲突审计

## 1. 新发现

V48 根据照片17/20/21将 A06 旋转台外径从错误的 Ø94 mm 收敛为 Ø66 mm 候选，但当时没有可靠厂商型号。V85 重新核对 Daheng GCM-110 系列原厂图后发现：

- **GCM-1101M**：整体约92 mm级，明显超出照片给出的55–75 mm合理直径范围；
- **GCM-1102M**：原厂外径 **Ø66 mm**，与当前 A06 照片/尺图候选完全一致；
- GCM-1102M 厂家图同时给出约 **21 mm总高、32×32 mm台面、±5°微调、±10′分辨率**。

因此 GCM-1102M 被提升为 A06 当前最高优先级厂家候选，但仍不是实物已确认型号。

## 2. 为什么不能直接把 A06 改成 GCM-1102M

照片17/18提供了另一组更直接的证据：样品银色顶面距面包板上表面约87–93 mm，中心值约90 mm。

当前 V48/V83 样品堆栈为：

- A16：8 mm；
- A06：33.2 mm场景候选；
- A02：20 mm；
- A07三层：9 + 7 + 12 = 28 mm。

因此样品顶面距面包板：

`8 + 33.2 + 20 + 28 = 89.2 mm`

处于87–93 mm尺读区间。

若直接把 A06 改成 GCM-1102M 厂家21 mm：

`8 + 21 + 20 + 28 = 77 mm`

这会比照片尺读下限低10 mm，比90 mm中心值低13 mm。

所以“Ø66完全吻合”不能单独证明当前完整 A06 几何就是 GCM-1102M。

## 3. 目前可能的解释

至少有三种尚未区分的情况：

1. A06 实际不是 GCM-1102M，只是直径巧合；
2. A06 是 GCM-1102M，但其上下还有约10–16 mm尚未识别的安装环、转接件或支撑层；
3. V48 对 A07三层或其他上方结构的照片拟合厚度仍需重新用原始尺图校准。

在没有进一步证据前，不允许为了匹配厂家型号而破坏已经由实物尺读支持的89.2 mm总高度。

## 4. V85 代码约束

V85 在 `src/v48-ruler-registration.js` 中建立厂家对照：

- GCM-1101M：92 mm级，判定不符合55–75 mm照片外径范围；
- GCM-1102M：Ø66 mm直径匹配；
- GCM-1102M：21 mm高度直接替换后样品顶面=77 mm；
- `GCM1102MDirectSubstitutionWithinRulerRange=false`；
- 最低缺失堆栈高度=10 mm；
- 按90 mm中心值缺失=13 mm；
- `A06VendorGeometryApplied=false`。

WebGL A06 元数据、BOM和零件详情同步显示该冲突。点击 A06 可直接看到“直径吻合但高度冲突”，而不是只显示一个看似确定的厂家型号。

STEP/CAD 继续保持当前 Ø66、33.2 mm场景包络，同时在验证报告中记录 GCM-1102M 的厂家尺寸与直接替换失败，不修改实体。

## 5. 下一步最有效的实物证据

优先级从高到低：

1. A06 侧面带直尺近照，直接测总高；
2. A06 底部与 A16 之间的侧视图，确认是否存在独立转接层；
3. A06 正面/底面铭牌；
4. A06 顶部到 A02 之间的接口近照；
5. 重新读取照片17/18中 A16、A06、A02、A07各层的单独高度。

在上述证据出现前，V85 将 GCM-1102M 保持为“**高优先级候选，禁止直接套用21 mm高度**”。

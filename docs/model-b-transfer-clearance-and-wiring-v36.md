# V36 模型 B：玻片右侧印章、夹具退台与温控线束复原（2026-11-04）

## 源证据和问题

- 用户最新截图显示玻片和玻片夹具处于加热台上方，而旧 B06 夹具会在向下移动时碰到金属热台。
- 用户明确要求 **PDMS 印章靠近玻片右侧边缘，整个夹具离开加热台平面投影**。
- 照片 110、145–151 支撑平台 B 的样品堆栈及夹具装配；照片 114、117、119、121、122 显示温控器、SE-600-48 电源、黑色内部模块和多条绝缘线束，但不提供可靠电路原理图或端子号。
- 旧版热台中央渲染为亮蓝色半透明凸起管线（内部真空气道的外观代理），与已确认的**顶部单一中心吸附孔**矛盾，V36 删除这类实体假凸起。

## 交互安全检查

- 新增 `film-drop` 玻片竖直下降预览滑条（0..-13mm）。运动的是 V25M 候选移动导轨和 B05..B07 转移末端，不带动底层固定磁座。
- `src/b-photo149-geometry.js` 的 `auditBLoweringPose` 考虑 film X 位移、样品 NFP X 位移和旋转后的方形热台 X 投影宽度。
- 当保守横向净空小于 2mm 时，继续下压预览被中止，控件退回初始高度。它是画面安全防护，不代表完整 3D 碰撞规划、力学承载或者原厂行程认证。
- `window.__modelBContactProbe` 读取真实网格，检查玻片、PDMS、金属夹具和加热块的相对边界与接触高度。

## B37/B38/B39 视觉线束

- `B37`：加热器双根独立带色线束，从陶瓷加热器**后侧**引出，经空间弧形线束到 B36 左壁 Ø10.6mm 候选穿线孔，再延伸至箱内的未指派连接区域。
- `B38`：测温反馈护套线，沿独立视觉路径进入同一穿线位置，在宇电 AI 控制器后方区域附近终止，**未指定传感器类型及端子**。
- `B39`：小型候选端子空间代理，位于控制箱内部闲置走线带，**并不证明原设备存在同一零件**。
- `B36` 左侧薄壁原有实心壁现在具有真正几何开孔，避免“导线穿过未开孔金属”。
- 近端外接线束在网页随样品台 X 与旋转参数更新起点；STEP 为默认安装姿态的静态独立实体。

**不可推断**：SE-600-48 是否直接给加热器供电、温控器的输出模块/输入制式、B23 内部模块的确切功能、任何线束颜色与极性对应、接地保护和 200°C 绝缘安全距离。因此此线束模型**不能用作电气接线图**。

# V58 | 平台 A 几何补全与独立操作位置候选

日期：2026-11-06。该页是工程复原记录，**不是实物认证或加工图**。

## 为什么单纯补夹具仍不正确

V57 的照片94左折边模型使用膜侧中心X=-116 mm、样品侧X=78 mm。这组历史场景坐标使A05远离A07；即使将两侧各12.5 mm名义行程用于相向调节，仍有约171.5 mm的场景代理缺口。这不是照片量出的真实距离，也不能通过虚构215 mm钢梁消除。

## 两种模型互不混淆

**照片94原姿态**：左折边；A05长度和膜/样品相对基准均未验证。网页按钮可以随时恢复此姿态。A17型号、上/下孔系及原厂匹配情况仍未知。

**V58操作位置假设**：为了检验单底板、磁吸座、两轴膜台、VC13Z升降、双摆角、夹具、玻片、PDMS和三层样品台能否在几何上相互接近，创建独立的明确标注的右折边候选。移动整套膜侧组件，不加长假想钢梁；本构型不声称照片实物有右折边或这些安装坐标。

## 完整组件装配

- 膜侧：唯一A01面包板 → A17磁吸底座 → A15 GCM-T25M双轴XY → A03 GCM-VC13M竖直13 mm → A04L未识别下摆角台 → A04 GCM-G40M60L上摆角台 → A05薄L折边 → A05C夹具候选（另有两枚**未确认螺纹**的候选压紧螺钉）→ A05G 76×26×1 mm玻片及右缘PDMS
- 样品侧：A01面包板（螺钉固定）→ A16 GCM-5306M 112×70×8 mm安装底座 → A06 Ø66 mm候选旋转台 → A02独立T25M单轴候选 → A07 9+7+12 mm三层样品支撑及28×28×1.4 mm候选样品片
- 显微镜底座A10仍用独立螺钉固定，非第二套公共底板

## V58仅用于操作姿态的候选尺寸

| 参数 | 候选值 | 核验状态 |
|---|---:|---|
| 膜侧磁座中心X | -46.75 mm | 场景求解，不是照片测量 |
| 样品侧中心X | 78 mm | 旧模型基准，未实物配准 |
| A05下折腿长度 | 52.1 mm | 仅为13 mm下降与样品上表面接触求解 |
| A05折边朝向 | 右 | **照片94原始构型是左折边**，镜像未证实 |
| 磁座和样品安装底座X向间隔 | 36.25 mm | 候选外包络相减 |
| 玻片 | 76×26×1 mm | 标准规格候选 |

## 软件/实体独立验收

- `src/a-working-layout.js`: 两级底座占位、两轴平移和转台旋转时的夹具边界、印章XYZ及VC13下降行程
- `src/app.js`: 独立工作候选/原照片模式、实时下降锁止、实际Three.js玻片/PDMS/样品接触探针
- `cad/build_assemblies.py`: 输出候选V58 STEP，包含A05/A05C/A05CU/A05CS1/A05CS2/A05G/A05GP、A07W
- `cad/validate_interfaces.py`: 固体之间接触/穿透、夹紧螺钉不穿玻片、磁吸座与样品座不重叠、PDMS与样品片正对
- `tests/a-working-layout.mjs`及浏览器端整机测试：参数与实际场景对照

## 仍不能宣称完成的实物问题

A17磁座真实型号及上下安装孔位；A05C真实夹持器型号/驱动/螺纹；A04L下摆角台型号；A05折边究竟在哪一侧及实际长度；A02是否确为单轴；A16至A06真实螺钉孔位；A07中间层材料；相机光路的实际工作距离；整个13mm真实运动过程有无其他干涉。这些需要可读原图或实物/原厂CAD复核。现有照片94没有提供右折边的证据。

**禁止直接依据V58候选值采购零件、钻孔、制造夹具或将其当作经过检定的自动下降控制策略。**

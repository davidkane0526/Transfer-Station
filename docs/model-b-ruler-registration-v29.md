# V29 模型B照片149立杆与杆夹重新配准（候选参数）

对照 149-r270.jpg（垂直尺）和 150.jpg（俯视整体），可确定：

- B27 **绝不可能只有25mm**：立杆在黑色套筒之上伸出一大截，越过连接第一根横杆的方夹，顶部仍可见外螺纹。
- 旧B05只画6mm法兰，缺失独立的 **黑色圆柱套筒**。照片149黑色外套的投影高度约4–5厘米；卓立PHSH-2长50mm可作**候选**，暂设B34；这不是从商标确认的型号。
- 立杆外露部分和安装总长都明显超出25mm。卓立PHSP12-4长100mm可作为候选几何，**暂不标成已识别SKU**。
- 圆柱PHUC-1本体有上下两独立Ø12横杆孔，名义中心距E=33mm。照片149显示两条钢杆**投影平行、分处上下两层**。B33是套筒上方单独的黑色方夹，不是PHUC本体的一部分。
- 观察到横杆从前端方夹连向PHUC再连向GCM-1302M；**B26连接块没有被证明是单独的可采购标准件**。继续作为可能接口而非已确证的零件。
- 场景候选高度采用B04顶面105mm、安装板105–111mm、黑套筒111–161mm、竖杆111–211mm、方夹175–205mm、上杆轴190mm、下杆轴157mm，**仅用于使总装内部机械连续**，不是尺子直接测得的相对光学平台绝对高度。

原厂资料：Zolix PHSH系列50mm型号PHSH-2、PHSP12-4长度100mm，PHUC-1 A60/BØ30/E33。原始照片与尺不共平面，因此只能对这些长度进行候选匹配。进一步确认型号需查看套筒的锁紧螺钉和底面接口、接杆端孔型。

必须保持网页和可导出STEP的B27/B34高度同步，并检查 B33 套筒无体积相交、两根杆孔轴不变及整机不丢样品/显微镜。

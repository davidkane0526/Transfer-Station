# V30：平台 B 横杆末端 / 玻片夹直接连接排查（照片108、149、150）

## 确认纠正

重新对照用户原图108和150，**下层水平Ø12钢杆直接延伸到黑色GCM-1302M夹具侧面**，没有此前模型B26的黑色Ø26套环及27mm竖直悬吊转接座。该座由早期错误的“直线悬臂”示意推导，并非实物可见零件，已从网页三维和CAD两处删除。

- **B25上层杆**：仅跨越B33方夹与B24 PHUC-1上孔，照片没有一根长杆继续穿过PHUC伸向物镜。将旧Ø12×150mm代理缩为Ø12×100mm场景拟合值，**不代表真实原厂SKU已确认**。
- **B28下层杆**：Ø12杆本体左端保留PHUC外的外露量，右端止于GCM夹具外侧立板；不允许Ø12实体深入Ø6候选孔或穿过黑色夹持器。
- **B26接口信息**：不再是要采购的单独转接块。CAD/网页现在只显示位于接杆端部的Ø6×10mm**候选**螺柱，BOM数量为0、归类“接口”；该螺纹仍待验证，不能据此采购。
- **B06 GCM-1302M**：在照片所示进杆侧新增与端部轴线同轴的Ø6.1候选孔，采用真实几何通孔而非与金属块相互穿模。制造商公开规格确认为M6、L=60mm、105g、夹板最大厚度≤5mm，**但M6孔的实际位置和安装深度没有由原始CAD确认**。
- **V25M活动安装板**：重新把安装板置于仍向上延伸的固定导轨之下。照片显示为安装在运动滑架一侧，而不是将整个载玻片机构架在导轨顶端。当前B05与B04固定机架的复杂干涉以及传力孔系尚待原厂3D或另一侧视角，不能直接将拟合板形交给加工。
- **玻片高度**：B06玻片随真实横杆端面配准；当前以玻片底面Y=125mm、金属热台顶面Y=98.2mm作**初始悬空观察姿态**，而非接触位置、实验初始值或工作距离实测。此处的26.8mm拟合间距明确标记候选。

### 自动门槛

1. B149立杆和黑色套筒仍须穿过B33，不得删除；PHUC原厂两孔距33mm固定。
2. B25不得保留旧150mm无支撑长尾。
3. B28 Ø12杆止于B06外侧接触面；B26 Ø6螺柱与B06真实Ø6.1孔同轴，且无实体碰撞。
4. B26不得重新出现粗套筒/悬垂方块，BOM不计为采购件。
5. B07玻片和B11加热块之间必须保持正向安全距离，且B08–B23整套样品台/显微镜/外设不能被错误删除。

**校验结论只能表示本候选三维几何与照片关系较以前一致，不是原厂制造装配认证。** 原始照片缺少各安装面的侧视剖面和详细孔系；真正要关闭“可加工性”问题，还必须对照OEM CAD、零件端孔和B05移动板机构。

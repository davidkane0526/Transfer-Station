# V166 · A08 Thorlabs TTL200-A 原厂图纸重建

## 已查实的模型错误

V165将A08建成Ø52×28mm实心圆柱，另叠加三道缺乏厂商图纸依据的装饰环和阻断光路的圆片。A14原模型向A08假定插入6mm，比原厂SM2肩部轴向长度3.2mm长；纠正A08为Ø55.9mm后，A14原Ø52.2mm内孔会与其中央壳体发生实体干涉。

## 厂商依据

Thorlabs工程图 TTN116903-E0W Rev B（2018-05-11）：中央壳体长度28.0mm、外径Ø55.9mm；两侧各有3.2mm的SM2外螺纹肩，因此完整机械包络总长为34.4mm。两端标称孔径分别为Ø31.0mm和Ø25.1mm。SM2系列名义直径2.035in，约51.689mm。图纸注明“仅供参考，不可用于制造”。

工程图镜像：https://www.oxxius.ru/upload/iblock/439/nnqcz1typ0xi4j8o1473uwc5izf6lyzm/TTN116903_E0W.pdf

## 修订

- V184更正后的A08网页及STEP：中央Ø55.9×28.0mm壳体、两个Ø51.689×3.2mm端段，完整总长34.4mm；切出Ø31.0/Ø25.1mm端孔及连续轴向光路。
- 删除旧三道装饰圈和挡光圆片，保持型号标识。
- A14候选镜筒：将6mm重叠约束改为3.2mm SM2端段包络。V184按A08真实总长调整为56.8mm，仍保留相机Y=323mm基准。
- 网页探针验证三段壳体真实包络与轴向光孔；STEP通过体积布尔检验，不容许A14穿过A08中央壳体。

## 未认证

真实光学玻璃、透镜面形、实际上下朝向、螺纹螺旋线及A08与A18T下端固定方式仍未证实。A14 56.8mm仍是依据当前相机高度和3.2mm插入量得到的场景候选尺寸，不是厂家实测SKU。平台A显微镜A10/A18分件边界仍未解决。

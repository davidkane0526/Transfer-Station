# V42 · VN-50真空泵照片与产品族外形联合复原

日期：2026-11-04

## 1. 复核结论

V41的STEP几何虽然通过了尺寸和连通性检查，但其外观仍有明显问题：泵头使用裸圆柱体表示，拉杆位于电机壳体上方，不能充分对应用户照片。V42重新建立了泵体外形，并把实物照片证据和同型号族产品图推导分开记录。

## 2. 实物照片直接支持的内容

### 照片120、123

可直接观察到：

- 黑色长形电机/泵体外壳，表面分布多排圆形通风孔；
- 外壳侧面有铭牌和警示标识；
- 泵体侧面可见纵向金属拉杆及端部支撑结构；
- 一端存在风罩/端部组件；
- 侧面铭牌区域不能被通风孔或其他结构遮挡。

### 照片123铭牌

可读信息：

| 项目 | 铭牌值 |
|---|---:|
| 型号 | VN-50 |
| 电压 | 220V |
| 功率 | 230W |
| 开放流量 | 53L/min |
| 真空度 | 680mmHg |
| 重量 | 约4kg |

因此，型号由照片123确认。照片120/123没有完整展示泵头顶部结构，不能仅凭这两张照片确认泵头内部结构、顶部滤杯和实际吸入口朝向。

## 4. V42几何调整

网页模型与CadQuery STEP按同一组名义尺寸建立：

1. **底板和安装脚**：底板候选外形200×110mm，四个安装脚按142×96mm候选孔距布置，候选通孔Ø6.2mm。
2. **电机主体**：保留黑色穿孔长形外壳和内部水平电机代理。
3. **端部组件**：保留端部风罩和圆形电机端盖代理。
4. **纵向拉杆**：两根拉杆调整到电机壳体两侧，并在两端增加四个支撑块，不再放置在壳体顶部。
5. **双泵头**：将V41的两个裸圆柱改为两个矩形泵头、底部法兰及顶部盖件。
6. **顶部附件**：增加一个金属接口候选和一个透明滤杯候选。其外形参考产品族图片，具体接口形式和方向仍未确认。
7. **通风孔**：顶部12个候选孔、侧面18个候选孔。侧面孔位避开铭牌范围，不允许穿过铭牌。
8. **吸入口**：B20I仍单独作为候选接口实体。其实际侧面、朝向和螺纹没有由照片确认，B40的连接终点仍需实物核对。

## 5. 自动检查

V42的CAD检查要求：

- 泵体包络为200×110×150mm候选尺寸；
- 四个安装脚及142×96mm孔距保持一致；
- 泵体合并为一个连通STEP实体；
- 两个矩形泵头、四个拉杆端部支撑均存在；
- 12个顶部通风孔和18个侧面通风孔保持贯通；
- 铭牌区域保持完整，不被侧面通风孔穿透；
- B20仍为独立外置泵体，不与B36控制箱或B22 LED适配器重叠；
- B20I保持为空心候选接口，B40软管不被实心几何堵塞。

网页端测试另行检查泵头、拉杆、安装脚、铭牌和通风孔的数量及位置。浏览器模型和STEP模型采用相同的名义几何尺寸和坐标映射。

## 6. 尚待实物核验

1. 泵体实际长、宽、高及安装孔中心距；
2. 两根拉杆的准确数量、直径、中心位置和端部支撑方式；
3. 双泵头的实际外形、相对间距和顶部接口细节；
4. 顶部透明滤杯是否与用户实物一致；
5. 真空吸入口的实际位置、方向、螺纹和密封形式；
6. 电源线入口及其他外接管线的位置；
7. 泵脚、减振垫和固定螺钉规格。

V42用于提高装配关系和外观复原精度，仍属于照片/产品族联合推导的工程代理模型，不可直接作为泵体加工图或采购验收依据。

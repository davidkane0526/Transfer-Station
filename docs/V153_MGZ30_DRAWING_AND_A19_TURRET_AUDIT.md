# V153 · MGZ30 工程图与 A19 转盘孔位差异审计

日期：2026-11-13。

## 1. Thorlabs Rev C 工程图可确认的结构信息

2012-08-14、Rev C、Thorlabs、零件号 MGZ30 的工程图明确标注：

- 立柱接口：Ø1.50 in，图面括号值 38.0 mm。
- 粗调行程：30 mm。
- 微调：225 µm/rev。
- 物镜转换盘：5 个 M26 × 36 TPI 接口。
- 随件适配器：5 个 RMS 转接件。
- 其他光学接口：SM1（1.035"-40）和 SM2（2.035"-40）。
- 安装孔：4 × 4-40 UNC。
- 图纸标题栏近似质量：4.55 kg。

## 2. 尺寸调用值与工程图限制

工程图中可读出的尺寸调用值包括：

185.0、30.0、202.2、80.0、57.8、268.7、73.7、68.0、291.7、100.2、130.0 mm。

这些值在数据结构中以“未完成坐标轴/尺寸端点映射”的列表保存。当前没有把它们强行映射成 X/Y/Z 外廓尺寸，也没有把它们用于默认模型约束。

工程图明确注明：
- “FOR INFORMATION ONLY NOT FOR MANUFACTURING PURPOSES”。
- 括号内数值为计算值，可能包含舍入误差。

因此该图适用于候选识别、接口核对和空间包络初筛，不是可直接用于制造的完整工程图，也不能替代原生 STEP。

## 3. 质量信息不混用

- 2012 Rev C 图纸标题栏：Approx. weight 4.55 kg。
- Thorlabs 现行产品页：Package weight approximately 1.79 kg。

一个是图纸标题栏的近似质量，一个是现行页面的包装重量，定义不同。当前不将二者当作直接矛盾，也不用于模型质量估算。

## 4. A19 转盘孔位差异

- 当前 A19 照片拟合只绘制两个可见物镜通孔和两支物镜。
- 这只表示照片中可辨的两个位置，不证明真实转换盘总共只有两个孔。
- MGZ30 原厂结构明确为五位置物镜转换盘。
- 因此 MGZ30 候选与当前 A19 两孔照片拟合之间存在未解决差异。需要转换盘底视图、未安装孔位照片或原厂 CAD 才能判断。

当前不增加另外三个孔，也不把两孔盘直接替换成五孔盘。

## 5. 当前模型决定

- MGZ30 仍是条件候选，不是已识别实机。
- 不修改默认 A18/A19 几何。
- A10/A18 后壳分界、Ø38.1mm 立柱接口与当前场景 Ø26mm 立柱之间的差异仍待实物核对。
- 原厂 CAD 文件尚未实际取得和验证。
- 所有未映射尺寸和近似质量只保留为候选证据，不作为制造或装配依据。

**V153 增加工程图证据与 A19 孔位冲突记录，不改变默认装配。**


## V154 更正：MGZ30 微调值的现行来源

V153 所记录的 225 µm/rev 是 2012 Rev C 工程图值；Volition 第三方资料页也列出 225 µm/rev。Thorlabs 2014 官方目录为 250 µm/rev。重新检查 Thorlabs 现行 MGZ30 商品页后确认，该页面未公布微调每转行程，因此不能把 225 µm/rev 归因于现行 Thorlabs 商品页。现行规格保持未决，两个历史/第三方来源值均不写入默认几何。

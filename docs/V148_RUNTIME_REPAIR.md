# V148 · 修复平台 A 控制柜后侧电缆密封圈材质未定义

日期：2026-11-12。

## 故障定位

V147 在 `src/details.js` 的 `enrichParts()` 中为 A33 温控柜增加三个后侧电缆密封圈。创建 TorusGeometry 时引用了 `rubber` 材质，但该函数作用域内没有声明此变量。浏览器在平台 B 切换到平台 A、执行 A33 装饰构建时抛出：

```
ReferenceError: rubber is not defined
```

该运行时异常导致 `pages.yml` 中的完整场景回归失败，发布任务被跳过。V147 的失败并非 CadQuery 碰撞检查失败，也不是显微镜几何校验失败。

## 修复

- 在 `enrichParts()` 的局部材质表中显式声明 `rubber`。
- 材质采用低金属度、较高粗糙度的深色弹性体外观，供 A33 后侧三个电缆密封圈使用。
- 不改变 A33 密封圈位置、尺寸、数量，不改变平台 A/B 的任何机械基准或装配结构。
- 不借此提交泵、控制器或其他外观装饰改动。

## 验证

提交后由 `.github/workflows/pages.yml` 自动运行：
1. `node --check src/details.js`；
2. `tests/model-b-visible-smoke.mjs` 完整浏览器回归；
3. 平台 B → 平台 A 切换期间的页面运行时错误检查；
4. 平台 A 专项照片视图和机械检查截图生成。

现有浏览器测试已在切换到平台 A 后断言页面错误列表为空，因此该回归可以直接捕获本次 `ReferenceError`。

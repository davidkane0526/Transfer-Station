# V19 原始影像逐机轴复核：装配顺序、手柄方向、磁座位置

日期：2026-10-30。资料来自用户最初上传的 `转移平台.zip` 中原图（已重新按EXIF方向显示）以及两段原视频；此次按**可见装配证据**修订模型，不把软件运行成功当作实物精度证明。照片未在公开仓库复制，仅记录文件编号和可见事实。

## 核心纠错：A 套有两个独立的 GCM-T25M

此前把两张照片中同型号的 GCM-T25M **错误合并**，导致 A 套右侧样品平台的 T25M 被移到旋转台上时，左侧 VC13M 下面的真实 T25M 消失。正确顺序：

- **A 载玻片侧：** 面包板 → **A15 GCM-T25M**（照片 `95.jpg`/`97.jpg`，右侧手柄）→ **A03 GCM-VC13M**（照片`97.jpg`，竖直移动机构/测微头）→ **A04 GCM-G40M60L**（照片`94.jpg`，右侧倾角测微头）→ 自制 L 型载玻片夹持杆（长度待测）。
- **A 样品侧：** 面包板 → **A06 旋转台** → **A02 另一台 GCM-T25M**（照片`100.jpg`，右侧手柄）→ **A07 自制样品加热块**（照片`79.jpg`/`100.jpg`）。

A02 与 A15 都是 GCM-T25M 型号，但**必须是两个有独立报价、独立零件ID、独立几何实例的部件**。

## B 载玻片臂：磁吸底座必须最底层

- 原图 `108.jpg`、`112.jpg` 清楚显示黑色标牌 **GCM-420302M OFF/ON** 在最底部，**磁吸底座直接放在光学面包板上**。
- 它的顶部直接承载黑色 **GCM-T25M** 横向平移台。其银色测微头在当前照片观察面朝左前方伸出（建模以 **−X** 表达）。
- **GCM-V25M** 在 T25M 上方。V25M 是**竖直导向板/升降台**，可见银色纵向测微部件；不能同时给 T25M 和 V25M 都画成朝 +X 伸出的手柄。
- 上部黑色大圆柱应识别为**Zolix 夹持器**，夹持两段不锈钢圆杆，**不是第二个磁吸底座**。其照片在 `107.jpg`、`108.jpg` 有清晰视角。
- 之后为后置横杆、右端玻片夹具与玻片。上杆长度、偏距、夹口高度仍是候选尺寸。
- B 样品侧（`110.jpg`、`111.jpg`）：光学面包板 → **GCM-1107M**（刻度盘和前向锁定杆，建模 +Z）→ **Zolix NFP-1462C**（右向银色测微头，建模 +X）→ **无金属过渡板的白色隔热层** → **单中心孔真空吸附块**。用户确认加热片导线与真空管在后侧。

**必须注意：模型坐标方向是为了统一两平台和可交互视角。网页 X 左右、Y 高度、Z 前后；STEP 使用 XY 为底面、Z 高度。因此 B 模型 −X 不是照片相机像素方向的精确测量，而是与统一局部正视图一致的映射。**

## 原厂组合机械图校验

[Daheng GCM-901604M 组合图 PDF](https://cdhoptics.ks3-cn-beijing.ksyun.com/jjwdz/1612323095702eFQBtxcrQgq7RZ9rgWIqSw.pdf) 说明该厂家存在 T25M 与 V25M 的正式组合，图中 65 mm 上平台及多方孔距可作为设计参考，但**该整套组合型号不是用户实物的确定型号**，其测微头标准朝向也可能与用户安装姿态不同。方向优先依据实物照片。

## 修订动作和校核

1. **交互网页**：分别为 B03(-X)、B04(+Y)、B08(+Z)、B09(+X)、A15(+X)、A03(+Y)、A04(+X)、A02(+X) 建不同的测微头朝向；扩大 B 磁座最低层的 OFF/ON 标识辨识；增加单独「放大载玻片侧」「放大样品侧」检查视角。
2. **实体 CAD**：重新构造以上每个模型对应的手柄轴向；A15 作为额外的独立 T25M，位于 A03 VC13M 正下方；A02 保留在 A06 旋转台上方。
3. **采购 BOM**：A15 另列一行、独立计价；禁止将相同型号误当作相同物理零件。
4. **回归测试**：`tests/photo-assembly.mjs` 校验结构/手柄与原始照片账本；`cad/validate_interfaces.py` 校验 B 磁座贴板、B03及B04上下接触、A 两台 T25M 分别位于不同轴组，以及每个 CAD 测微头轴向。

# V141 · 平台 A 温控箱右移

**用户要求（2026-11-12）：** “温控箱 右移”。

将“右”解释为 A 平台模型在当前前视图中的 **+X 方向**；无指定数值，以 80 mm 作为本次可调的工程候选偏移。

| 组件 | 原中心 X(mm) | 新中心 X(mm) | 处理 |
|---|---:|---:|---|
| A33 温控箱 | 260 | 340 | 整体右移 80mm，面板、壳体与指示灯随动 |
| A13 箱内 SSR | 260 | 340 | 随箱体右移，保留相对位置 |
| A25 测温反馈接口 | 305 | 385 | 同步右移，与反馈线束端点一致 |

| A30 真空泵 | 350 | 350 | 不移动 |
| 平台 B | — | — | 不修改 |

坐标：WebGL 世界 X 为左右，Y 为垂直；STEP 的 X 同为左右，Z 为垂直。模型中电气端仍属候选服务区域，不代表已经确认端子接线。

## 验证要求

- 浏览器场景同时断言 A33/A13/A25 新坐标及 A12/A30 不变。
- A23 和 A24 线束的最终结点与移动后的 SSR/测温接口重合。
- STEP 检查温控柜与箱内 SSR 的横向重叠关系，以及对 LED 驱动器、真空泵的相互避让。
- 验证结果以真实 GitHub Pages 成功发布及 CAD 构建结果为准。80mm 为用户未指定精确距离时的工程候选，后续可按实物比例调整。

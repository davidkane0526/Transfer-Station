# 模型 B 严重错误排查（V27，2026-11-03）

## 审查结论

本轮**不把 A/B 历史照片编号直接当成客观设备身份**。94/95/97 在早期表格中列为 A，但新用户明确要求按这组近照纠正当前 B，因此 B 的新照片候选暂保留，**不能**据此认为旧 108/109 与当前 B 属同一机构，也不能从照片94/95/97推出样品侧 110/111 与其共台。

重要的程序错误是 UI 将『B 新照片候选』和『B 旧照片样品侧』渲染在一张整机图里，却没有指出这不是一个已证实的整机装配。现在网页将显示机械接口审计，包括距离和缺失接口。

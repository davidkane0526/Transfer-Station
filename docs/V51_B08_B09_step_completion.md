# V51 STEP补全：B08 GCM-1107M 与 B09 NFP-1462C

## 为什么补建

此前B08旋转台和B09单轴平台已经存在于WebGL装配和BOM，但CadQuery STEP生成器中没有对应零件。这导致STEP总装缺少实际承载链中的两级机械部件。V51将其补入平台B STEP，避免只在网页预览中出现。

## B08：Daheng GCM-1107M

- 型号：GCM-1107M
- 外形候选/目录尺寸：Ø94×33.2mm
- CAD结构：23mm下部旋转体 + 10.2mm上部转盘
- 顶面：9个25mm网格M6候选孔
- 操作者侧：前向锁止手柄
- 装配：B35顶面直接承托B08，B09固定底座再安装于B08上表面

## B09：Zolix NFP-1462C

- 外形：65×65×23mm
- 运动：单轴X，不补画Y轴测微头
- 固定底座：11mm，4×Ø6.5通孔及Ø11沉孔，50mm方形孔距
- 活动组件：2mm下层 + 10mm上层
- 活动顶面：9-M6 + 4-M3孔系代理
- 侧面：固定底层4个、活动上层3个可见孔位，孔径与螺纹未确认
- 测微头：按照片安装方向指向右侧（+X），采用外壳盲孔、Ø7.2mm轴、空心Ø18mm套环及空心Ø22mm旋钮代理。完整组合长度约177.5mm，落在厂家图纸155.5–180.5mm总长范围内；细部仍为候选

## 当前装配高度

以B35顶面为基准：
- B35顶面：Z=32.0mm
- B08顶面：Z=65.2mm
- B09顶面：Z=88.2mm
- B10隔热层底面：Z=88.2mm

B08与B09的接触面、B09固定/活动层的11+2+10mm高度链已加入STEP接口校验。

## 验收边界

本次补建解决STEP中缺失B08/B09实体的问题，不等于所有细节均为原厂CAD。B08固定沉孔方向/深度、B09侧孔直径与螺纹、测微头内部结构及动态行程极限仍需原厂原生CAD或实物复核。

### V51.2：NFP测微头接口和总长校正

将CAD测微头由相互错位的实心圆柱代理改为同轴嵌套结构：外壳侧面Ø8mm盲孔、Ø7.2mm测微轴、Ø18mm空心套环及Ø22mm空心旋钮。方向与照片110一致，安装后朝操作者右侧。整体从NFP固定底座左端到旋钮末端约177.5mm，符合厂家给出的155.5–180.5mm总长范围。验证器同时检查轴/外壳、轴/套环、套环/旋钮之间无实体干涉。该检查确认CAD代理几何，不替代厂家原生CAD或行程实测。

# V161 · A18 可见表面审计修正

## 背景

V160 的 A18 粗调手轮比例调整后，GitHub Actions 的 `model-b-visible-smoke.mjs` 在主光学近景检查中失败。JavaScript 语法检查通过，失败断言为：

`A18 main audit must expose at least one actual coarse focus wheel`

失败日志显示，原检测射线分别首先命中 A18 主体和 A21 照明支撑件。原有 `_auditAnyVisibleSurface()` 仅从目标对象的轴对齐包围盒取中心、六个面中心作为采样点。该方法并不保证采样点位于真实三角网格表面，尤其不适合检测轴线经过旋转的圆柱手轮。

## V161 修改

1. 从目标 Mesh 或 Group 的实际子 Mesh 中读取三角面。
2. 将三角面顶点转换到世界坐标，计算三角面中心和面法向。
3. 按相机视线与面法向的夹角排序，抽样最多 24 个真实表面三角面中心。
4. 从相机向采样点发射射线，仍以场景中第一个可见命中对象判断遮挡关系。
5. 不隐藏 A21，不设置透明跳过项，不更改 A18 的几何尺寸或装配坐标，也不放宽现有可见性断言。

## 验收

- `node --check src/app.js`
- `node --check tests/model-b-visible-smoke.mjs`
- GitHub Actions 浏览器回归必须通过 A18 主近景粗调轮可见性断言。
- A18 左右两侧手轮仍须分别从对应侧视图直接可见。
- A18/A19 光学链、A11 独立照明头及 A10 支撑结构的既有断言保持不变。

## 证据边界

本次只修复可见表面检测方法，不代表确认了 A18 的真实厂商型号。照片 191–193 在仓库中仅有 128 × 170 px 的压缩预览，无法可靠识别 A18 铭牌、镜体环孔径、转换盘孔数或 A10/A18 后壳分缝。Thorlabs MGZ30、LYLIGHT FR8425/FR5025CF 等仍为候选，不得将候选型号或当前代理尺寸用于采购和加工。

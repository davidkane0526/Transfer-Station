# V192 · A18 固定侧网实体连接与照片左右顺序校正

日期：2026-11-17。

## 发现的问题

V191 的 CAD 装配成功生成 STEP，但接口验收在 A18 固定侧网 A18FW2 处失败。其原因不是导轨方向反了，而是右侧固定网的 X 范围与偏置后的焦点外壳之间留下 2mm 间隙，导致固定侧网没有连接到静止机身。

## 坐标约定

- 从参考透明底照片所对应的 **+Z 正面**观察。
- **屏幕右侧为 +X，屏幕左侧为 -X**。
- A18 右侧固定网位于 +X 一侧，并与右导轨 A18G2 对应。
- 左侧固定网位于 -X 一侧，并与左导轨 A18G1 对应。
- 水平侧向光学筒位于照片右侧（+X），线缆和正面刻度盘位于照片左侧（-X）。

## V192 修改

1. WebGL 中右侧固定网中心由局部 X=48mm 调整至 X=45mm，保持其位于 +X/照片右侧，同时让其左边界与偏置机身产生 1mm 的实体搭接。
2. STEP 中右侧固定网同步由全局中心 X=cx+48mm 调整至 X=cx+45mm。
3. 左侧固定网不移动，左右固定网仍按 -X 到 +X 的顺序排列。
4. 增加 CAD 断言：两侧固定网必须分别连接机身和对应导轨，且右侧固定网必须与机身有实体交叠。
5. 增加 WebGL 断言：正面参考视角下，左侧固定网世界 X 必须小于右侧固定网世界 X。

## 验收边界

这次调整只修复固定侧网的 2mm 连接断缝，不改变外壳中心相对光轴 -13mm 的照片拟合偏置，不改变右侧 145mm 中空侧筒、左侧线缆、前面刻度盘或中央光轴。所有照片拟合尺寸仍非实测值，模型继续作为装配关系审查模型，而非加工图。

# V51 机械复核记录：A17 / B02 / A05

## A17：撤销GCM-420302M与13孔型套用

A照片22/24只支持前侧银色滑槽板、中央滚花旋钮和两颗面板螺钉。现有A照片没有可读铭牌，也没有展示A17顶面和底面孔系。此前将其与大恒GCM-420302M目录外观关联，并把B02的5-M6+4-M4+4-M3共13孔复制到A17，证据不足，现已撤销。

WebGL和STEP改为中性外廓代理：65×65×20mm仍仅是照片拟合候选，顶部不再绘制任何未经观察的孔；这不代表实物顶面无孔，而是将隐藏接口明确标记为未建模。保留照片可见的前面板滑槽、旋钮及两颗螺钉。A17型号、磁吸开关功能、底部接口、真实孔距、螺纹和承载仍待补充正面/顶面/底面/铭牌照片。B02的GCM-420302M身份仅属于B套。

## B02：补齐中央孔

B02铭牌已确认GCM-420302M。模型此前遗漏中央M6孔，现按厂家目录补齐5-M6（含中心）、4-M4、4-M3。该修改只补全孔系，不代表磁座额定负载已在当前装配中验证。

## A05：分离连接片、夹具与玻片

照片94中的A05是L形薄金属折弯连接片，不能将其与玻片夹具或玻片耗材合并。BOM拆分为：
- A05：L形折弯连接片，尺寸、板厚、折边和下端连接待测绘；
- A05C：GCM-1302M / GCM-1311M夹具比对候选，未确认，不加入已安装几何；
- A05G：76×26×1mm标准载玻片尺寸候选，采购前需按实物尺图复核。

不得把B平台B06已确认的GCM-1302M身份移植到A05C。

## 验收边界

A17型号及顶/底面孔位、A05夹具和玻片实际尺寸均未完成实物确认。上述几何是有证据等级标记的候选模型，不作为直接加工或采购图。

- WebGL与STEP将A17顶部接口改为中性未建模代理，不把“未建模”表述成“实物无孔”。

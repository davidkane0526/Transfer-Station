# V149 · 平台 A 显微镜 A10/A18 厂商候选重新审查

日期：2026-11-12。

## 1. 新增候选：LYLIGHT FR5025CF

LYLIGHT 厂商产品页和产品 PDF 展示的是一个完整的粗/微调 E-arm 调焦架：调焦块、连接臂和镜体环构成一体组件。厂商资料标注：

| 项目 | FR5025CF 厂商数据 |
|---|---:|
| 立柱安装孔 | Ø25 mm |
| 镜体接口 | Ø50 mm |
| 厂商产品图标注中心距 | 165 mm（尺寸端点基准未充分说明） |
| 微调精度 | 0.02 mm |
| 调焦形式 | 粗调 + 微调 |
| 结构 | 一体式 E-arm |
| 外观 | 黑色产品图 |

来源：
- [LYLIGHT FR5025CF 产品页](https://www.lylight.com/product/coarse-and-fine-focus-mount-50mm25mm-with-fine-adjustment-focusing-knob/)
- [LYLIGHT FR5025CF 产品图/规格 PDF](https://www.lylight.com/wp-content/uploads/2024/05/FR5025CF-coarse-and-fine-adjustment-focus-rack-LYLIGHT.pdf)

**结构意义：** 若实机与 FR5025CF 属于同一结构族，当前模型中的 A10 横臂可能是 A18 调焦架的一体式 E-arm，而不是独立采购件。此前把 A10 横臂和 A18 调焦块分别建模，可能造成错误的零件边界或重复计件。

**尺寸基准补充（V150）：** FR5025CF 产品图标注“中心距离 165 mm”，而同一 PDF 的完整支架示意另标 135 mm。资料没有充分说明两条尺寸线的端点基准，不能把 165 mm 直接解释为当前立柱中心至光轴的距离，也不能将 135 mm 与 165 mm 视为同一尺寸。二者均只作为厂商图面标注保存，当前装配不采用这两个值作为约束。

**证据限制：** 当前检索到的是产品页和产品图/规格 PDF，并非完整尺寸工程图或原生 STEP。除厂商明确标注的接口孔径、中心距标注和微调精度外，焦块外廓、臂厚、安装孔位、紧固件、环座壁厚及内部调焦机构仍未知。FR5025CF 目前只能作为高优先级结构候选，不能作为实机型号认定。

FR7625CF 为 76mm 镜体环、25mm 立柱孔的粗/微调 E-arm 变体。厂商产品页明确标注 76mm 镜体环和 25mm 立柱孔，但当前公开页面没有提供可核验的中心距和微调精度。

来源：

它只能作为 76mm 环径变体对照。当前照片预览不足以确认或排除 76mm 环，不能再以“照片没有显示”作为确定性否定。

## 3. 修正 Thorlabs MGZ30 的历史判断

Thorlabs 官方 2014 目录明确说明，每一台 Post-Mountable Focus Block（包括 MGZ30）本体均包含五物镜转换盘，五个接口采用 M26×36 TPI，并附五个 RMS 转接件。MGZ30 具有 30mm Z 行程、粗调 40mm/rev、目录微调 250µm/rev、Ø1.5in（38.1mm）立柱安装，并兼容 30mm cage、SM1 和 SM2。

来源：
- [Thorlabs MGZ30 官方目录（1739）](https://www.thorlabs.com/catalogpages/v21/1739.pdf)
- [Thorlabs MGZ30 产品页](https://www.thorlabs.com/focus-block-and-accessories)
- [MGZ30 Rev C 工程图（2012-08-14）](https://oxxius.ru/upload/iblock/645/z5e9spl0ippo9o526roo4qt3zxyzg0bk/21618_E0W.pdf)

**历史错误更正：** V146 曾将五物镜盘归属到完整 T-Scope 系统，称 MGZ30 单独调焦块不含五物镜盘。这一判断错误。五物镜盘是 MGZ30 本体的厂商确认特征。

**规格版本差异：** 2012 Rev C 工程图标注微调 225µm/rev，2014 目录标注 250µm/rev。未获得对应版本的进一步说明前，不将两者合并为同一数值。

完整 T-Scope 是另一套系统，配套管镜为 ITL200。当前 A08 按 TTL200-A 建模，因此不能将当前整套光学组件直接认定为完整 T-Scope；但这不影响 MGZ30 单独调焦块本体具有五物镜盘这一事实。

当前 MGZ30 研究网格尚未重建五孔载体的精确孔圆、转接件和安装结构，不能称为原厂 CAD 复刻。

## 4. 候选矩阵与当前决定

| 候选 | 已知结构特征 | 与当前模型的关键待核项 | 当前等级 |
|---|---|---|---|
| LYLIGHT FR5025CF | 黑色一体式 E-arm；Ø25立柱孔；Ø50镜体接口；165mm中心距 | 实机柱径、环径、中心距、A10/A18一体边界 | 高优先级结构候选 |
| Thorlabs MGZ30 | 黑色封闭焦块；Ø38.1立柱；30mm行程；本体五物镜盘 | 实机柱径、五孔盘、后夹持壳体和 A10/A18 分缝 | 条件候选 |
| LYLIGHT FR7625CF | Ø25立柱孔；Ø76镜体环；粗/微调 | 76mm环径和中心距未确认 | 同族对照 |
| Boli SA02041502 等 | Ø25立柱孔；Ø76mm镜体环；部分型号中心距 140–156mm | 当前预览不足以确认或排除 76mm E-arm | 未决对照 |
| Olympus/Evident BXFM-F | 84mm机身宽；Ø32H8立柱孔；30mm行程 | 银色开架外观与实拍黑色封闭机身不一致 | 次候选 |

**当前决定：**
1. FR5025CF 是目前最值得优先核对的一体式 E-arm 结构候选，但不是已识别实机。
2. MGZ30 降为条件候选。其 38.1mm 立柱和五物镜盘必须与实物逐项核对。
3. A10/A18 零件边界继续保持未闭合；A10 横臂不得单独采购或加工。
4. 默认 A18/A19 几何不因候选型号而改变；没有候选厂家几何应用到正式装配。

## 5. 下一步必须闭环的实物证据

- 立柱外径实测，区分 Ø25mm 与 Ø38.1mm 候选。
- 调焦架镜体环内径实测，区分 Ø50mm 与 Ø76mm 候选。
- 实测本机立柱中心至光轴距离；与厂商图中 165mm 产品图标注、135mm 整机示意标注分别对照，不预设两者基准相同。
- 若需要按 FR5025CF 复刻，向厂商确认 165mm 与 135mm 尺寸线各自的起止基准。

- A19 转盘底视图，确认实机是两位置还是五位置结构。
- 调焦旋钮侧视、顶部和背面照片，确认粗/微调旋钮、夹持锁柄和紧固件位置。
